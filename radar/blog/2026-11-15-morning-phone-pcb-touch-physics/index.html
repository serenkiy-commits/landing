lingbot-touch: общее представление тактильных сигналов

Robbyant/lingbot-touch в описании GitHub — Learning Heterogeneous Tactile Representation for General Dexterous Manipulation. README называет LingBot-Touch моделью представления тактильных сигналов на базе JEPA: общий Transformer и предсказание латентного представления по пространственно-временному контексту. Три модальности интерфейса: magnetic, piezoresistive и visuotactile. Статья — arxiv.org/abs/2611.12806. Страница проекта — technology.robbyant.com/lingbot-touch. Веса Tiny и Small лежат отдельно на Hugging Face и ModelScope: в каталог чекпоинта кладут пару config.json и encoder.pt. README пишет, что к репозиторию модели нужен аккаунт с доступом. В этом репозитории — замороженный target-энкодер и утилиты, которые достают признаки токенов и их адреса по времени, пальцу и точке.

Примеры README идут двумя ветками: Sharpa в visuotactile, XHand в magnetic. Команды инференса в README запускаются на CPU, для совместимого GPU NVIDIA там указан --device cuda:0. Окружение, которое README называет проверенным: Linux, Python 3.12, PyTorch 2.11. Для нового сырого расположения такселей README просит проверенную геометрическую калибровку. Образцы Sharpa и адаптер XHand, по README, уже содержат свои координаты, второе преобразование к ним применять не нужно. Чтение по умолчанию README советует через cross-attention к токенам, а не через среднее или максимум: после общего Transformer токен уже несёт контекст других точек и моментов времени.
