xcslot: тёплые слоты сборки Xcode

ertembiyik/xcslot в описании API — тёплые слоты сборки Xcode для параллельных кодинг-агентов. README объясняет, почему свежий git worktree собирается заново: Xcode переиспользует данные сборки только по тому же пути и тем же меткам времени файлов. Программа держит несколько слотов по фиксированным путям, копирует туда worktree и запускает сборку там, так что первая сборка нового worktree становится инкрементальной. Команду README ставит префиксом к уже привычному xcodebuild: аргументы проходят дальше, код выхода возвращается как есть, пути в выводе указывают на worktree. README называет macOS на Apple silicon и Intel и клиентов, которые сами вызывают shell: Claude Code, Codex, Cursor и остальные. На проекте IceCubesApp README пишет, что первая сборка свежего worktree сокращается с 85 с до 3,9 с, и отсылает метод в docs/benchmarks.md. Этот выпуск замер не повторял. Лицензия MIT, язык в снимке — TypeScript. Смотреть тем, кто гоняет несколько агентов по Xcode-проекту на Mac и упирается в холодную сборку каждого worktree. MarginCue: карточка до отправки промпта

fus3r/margincue по описанию API показывает, как Claude Code или Codex прочтёт промпт до старта, и даёт переключить выбор, который агент сделал бы сам. README раскладывает это на чтение ещё во время набора: одна строка о том, что агент выдаст и как поймёт просьбу, проверка имён из промпта по коду проекта и флажок, если имени в коде нет, плюс переключатели для того, что промпт оставил открытым. Пока Claude работает, README описывает его решения как переключатели: смена доходит на следующем шаге, без остановки. После хода README обещает квитанцию: что задали вы и что выбрал Claude. Установку README пишет для Claude Code 2.1.326 или новее как плагин и для Codex CLI 0.171 или новее при Node 20 или новее. Про цену README говорит прямо: в Claude Code каждое чтение и каждый эскиз — небольшой вызов Haiku через вашу сессию и идёт в план; в Codex чтение идёт через ваш вход, на самой лёгкой модели аккаунта. Содержимое файлов, по тексту README, с машины не уходит: наружу уходит черновик так же, как обычный промпт, плюс оглавление папок и имена файлов. Телеметрии README не заявляет. Лицензия MIT, язык в снимке — TypeScript. Смотреть тем, кто уже пишет промпты в Claude Code или Codex и хочет увидеть развилку до отправки. enwove/flyx в описании API — локальный движок вывода LLM без зависимостей, в бинарнике около 50 МБ: длинный контекст без урезания окна, настройка под конкретный GPU, встроенное спекулятивное декодирование и веб-дашборд. Лицензия Apache-2.0, язык в снимке — C++. Смотреть тем, кому нужен локальный OpenAI- или Anthropic-совместимый сервер на машине с NVIDIA и кто готов читать чужие замеры отдельно от факта сборки.
