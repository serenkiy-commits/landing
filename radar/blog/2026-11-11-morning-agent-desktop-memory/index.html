wrapvm: десктоп-VM для агента

tobi/wrapvm — готовая десктоп-VM для агентов. Один Containerfile публикуется CI как ghcr.io/tobi/wrapvm:desktop, Smolfile загружает его как VM smolvm. Внутри Xvfb и XFCE. Просмотр в браузере — через voxl на порту 6080 с паролем. Постоянный Google Chrome с CDP на порту 9222. Рядом agent-browser (браузер) и agent-desktop (computer use через AT-SPI) от vercel-labs, скиллы desktop и browser в ~/.agents/skills, PulseAudio и ffmpeg для записи. Основа — образ tobi/wrap. Язык Dockerfile, 342 звезды, push 04.11.2026. Лицензия в репозитории не указана: для коммерческого использования это нужно учитывать. На момент запроса репозиторий не был архивным.

Кому: тем, кто хочет дать агенту изолированный рабочий стол с браузером.

good-door: секреты через elbab

dreamers-laboratory/good-door — CLI elbab, шифрованное хранение секретов для людей и агентов. Логика утилиты: атакующие редко ломают шифрование, они читают то, что лежит открыто — ~/.aws/credentials, SSH-ключ без пароля, .env в старом бэкапе, токен в транскрипте агента. elbab шифрует это через age. Ключ каждой машины хранится в системном хранилище или чипе: на macOS это Keychain или Secure Enclave. Агенты могут пользоваться секретами, не видя их. Нужны Python 3.9+ и age 1.2+, при init есть recovery-файл. Лицензия MIT, язык Python, 266 звёзд, push 06.11.2026. На момент запроса репозиторий не был архивным.

Кому: всем, у кого ключи и .env лежат рядом с агентами.

auto-ontology-mcp: семантический слой как MCP

gogoymh/auto-ontology-mcp — MCP-сервер, stdio и streamable HTTP. Даёт ассистенту строить и запрашивать семантический слой по данным на базе NVIDIA Auto Ontology и личную базу знаний. Работает с Claude, ChatGPT, Codex и другими MCP-клиентами. Отдельный ключ LLM API не нужен. Нужен Python 3.12+. Лицензия Apache-2.0, язык Python, 312 звёзд, push 10.11.2026. На момент запроса репозиторий не был архивным.

Кому: тем, кто хочет, чтобы агент понимал структуру своих данных, а не только текст.

learn-from-lessons: уроки из ваших правок

assassin808/learn-from-lessons читает уже лежащие на машине транскрипты Claude Code, Codex и opencode. Находит места, где вы поправили агента — «не пушь пока», «я спросил почему, а не просил менять», — и делает короткие уроки с точной цитатой-источником. Команды: lessons scan, lessons dream (через ваш собственный claude/codex CLI), lessons view (список, граф, доказательства), lessons inject --target CLAUDE.md --apply. Ставится через pipx. Python 3.9+, без зависимостей, всё локально. Лицензия MIT, язык Python, 33 звезды, push 09.11.2026. Репозиторий создан 09.11.2026 — совсем свежий. На момент запроса не был архивным.
