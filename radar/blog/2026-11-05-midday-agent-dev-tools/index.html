agent-autoloop: агент работает в фоне и зовёт вас только за решением

Описание KKKKhazix/agent-autoloop на китайском: командный агент в фоне сам берёт задачи и доводит их до конца, а карточку присылает только когда нужно решение человека. В README это лёгкая «средняя прослойка» для автоматизации. Ядро планирует задачи без внешних зависимостей, а источники событий, агенты, каналы уведомлений и выкладка кода сделаны сменными плагинами. Запускается одной командой на Mac или Linux, нужны Node 24, Git, curl и уже авторизованный командный агент, например Claude Code или Codex. Для вопросов к человеку README называет Feishu, DingTalk, WeCom, Slack, Discord и уведомление на рабочем столе. Версия для Windows в README помечена как «待定», то есть пока не готова. Лицензия MIT, TypeScript, 2900 звёзд, push 5 ноября 2026.

Репозиторий создан 3 ноября 2026, то есть ему два дня. Как он ведёт себя на длинных задачах, в карточке не измерено: это проверяют командой agent-autoloop try из README.

reason-network: агенты разных людей переписываются между собой

Описание reason-machines/reason-network: агенты для кода в команде общаются друг с другом. Проект ставит на компьютер небольшой демон. В README заявлены сквозное шифрование и связь напрямую между компьютерами. Агентам даны инструменты list_team, send_message, message_status и ask_user под MCP-сервером reason-network. Среди совместимых агентов README называет Claude Code, Codex, Cursor, Gemini CLI, Copilot CLI, opencode и другие. Для облачных ассистентов указан отдельный MCP-сервер. Чтобы войти в сеть, нужен аккаунт Reason. Лицензия Apache-2.0, Rust, 1516 звёзд, push 5 ноября 2026.

Если у вас несколько агентов на разных машинах, смотреть стоит на раздел «Get started» в README. Насколько это удобно в вашей команде, видно только после установки.

blaze: пересборка Rust за миллисекунды

Описание indexable-inc/blaze: инкрементальные сборки Rust до 92 раз быстрее, чем cargo и rustc. Команды blaze build, check, run, test и bench работают как у cargo. Демон остаётся запущенным и после правки пересобирает только изменённое. В README приведена таблица замеров для Linux x86-64: у ripgrep 508 мс у cargo против 56 мс у blaze, у bun 9,11 с против 451 мс. Там же оговорка: эти числа относятся к первой версии blaze, а вторая ещё не измерялась. Поддерживаются macOS на Apple silicon и Linux. Лицензия Apache-2.0, Rust, 1991 звезда, push 5 ноября 2026.

Цифры скорости взяты из README автора, мы их не перемерили. На своём проекте результат может отличаться.

reylo: .sql-файлы как типизированные импорты TypeScript

colinhacks/reylo позволяет импортировать .sql-файлы в TypeScript с полным выводом типов и без генерации кода. Типы запроса следуют за SQL и проверяются по схеме вашей dev-базы, поэтому опечатка в названии столбца становится ошибкой типов. По README поддержаны Postgres, MySQL, SQLite и DuckDB (в превью), а драйвер можно взять свой, например pg, postgres.js, mysql2 или better-sqlite3. Проект опирается на «content mappers» из TypeScript 7.1, который на момент README в бета-версии, и требует Node 24 и запущенную dev-базу. Лицензия MIT, по API основной язык Rust, 1503 звезды, push 5 ноября 2026.

Из-за беты TypeScript 7.1 перед использованием в рабочем проекте стоит отдельно проверить совместимость.
