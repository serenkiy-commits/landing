Anvil: нативный агент для кода на Mac

deeeeone/Anvil — десктопное приложение на SwiftUI в духе Claude Code и Codex: открываете папку, описываете правку, агент читает, правит, запускает и тестирует код. По README агент общается с моделью простым текстовым протоколом, а не встроенным вызовом инструментов, поэтому подходит почти любая чат-модель, включая дешёвые и бесплатные; для слабых моделей добавлены проверки — тесты до статуса «готово», ревьюер читает diff, после повторных неудач задачу берёт другая модель. Каждая правка показывается как diff до записи, каждый запрос — точка отката, есть четыре режима разрешений. В одном окне — терминал, превью в браузере, которым агент управляет, iOS Simulator, git, GitHub и языковые серверы; крупную задачу можно разбить на подсессии в отдельных git worktree. Провайдеры: любой OpenAI-совместимый API через JSON-файл, плагины из GitHub, а также веб-аккаунты ChatGPT и Gemini. Требование из README — macOS 15 и новее, версия 0.1.0. Кому: тем, кто на Mac и хочет агента для кода со своей моделью и просмотром каждого diff. minecraft-server-on-orange-cloud: сервер Minecraft целиком на Cloudflare

sshkeda/minecraft-server-on-orange-cloud — развёртывание сервера Paper для Minecraft Java в своём аккаунте Cloudflare одной командой, без VPS и проброса портов. По README Spectrum принимает TCP-подключение игрока на порту 25565 и отдаёт его Worker, тот — Durable Object, который запускает контейнер Paper. Через 10 минут без игроков мир сохраняется и сервер засыпает; следующий игрок будит его примерно за 30 секунд. Пока сервер работает, мир сохраняется в R2 примерно каждые 5 минут. Автор прямо пишет, что это не бесплатно: фиксированно $25–30 в месяц (Workers Paid за $5 и зона на тарифе Pro или Business, потому что Spectrum не работает на бесплатных зонах) плюс оплата контейнера, пока он не спит. Для развёртывания нужны macOS или Linux с glibc, Bun 1.4.4+, Node.js 22.12+ и Docker; Windows и Alpine не поддерживаются. Кому: тем, кто держит небольшой сервер для друзей и не хочет администрировать VPS. RustText: портативный редактор для Windows

Illson/RustText — текстовый редактор для Windows x64 в виде портативного EXE, README на русском. Несмотря на название, GitHub определяет язык проекта как C#. Возможности по README: несколько курсоров, колоночное выделение, миникарта, поиск и замена по регулярным выражениям, файлы бок о бок. Рабочие пространства — у каждого свои вкладки, черновики, раскладка и тема. Черновики без имени не теряются, а локальная история версий файла работает без git. Для логов — поиск по всему файлу, фильтры по уровням, слежение за новыми строками и ротацией; автор указывает проверку на файле 20 ГиБ. Есть подсветка и форматирование JSON и JSON Lines, сравнение списков, генератор строк и проверка HTTP/HTTPS/SOCKS5-прокси. Кому: тем, кто на Windows работает с большими логами и конфигами и ищет замену Sublime Text. NvidiaGsyncTweaks: G-SYNC без скачков 60/120 Гц

Orbmu2k/NvidiaGsyncTweaks — утилита для Windows 10/11 с видеокартой NVIDIA, которая меняет скрытые настройки VRR драйвера без ручной правки реестра. Проблема по README: на мониторах с высокой частотой драйвер включает удвоение кадров (LFC) уже около 58–65 FPS, а не на реальном минимуме VRR, и игра около 60 FPS скачет между 60 и 120 Гц — на OLED это видно как мерцание яркости, на других панелях как подёргивания. Причина — скрытый параметр vrrFrameSplitBehavior, описанный в треде на Reddit, ссылка на него есть в README. Приложение само находит GPU и ключ драйвера, показывает, что будет с монитором, и применяет настройку с перезапуском драйвера (для этого нужны права администратора). Нужен Windows App Runtime 2.x, архив — на странице Releases, автор указывает проверку на драйвере 621.12. Кому: владельцам OLED и мониторов 240/360 Гц с G-SYNC, у которых мерцает картинка около 60 FPS.
