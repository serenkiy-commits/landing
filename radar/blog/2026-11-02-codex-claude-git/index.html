lazycodex: план и проверка внутри Codex

Описание репозитория code-yeongyu/lazycodex говорит о harness для сложных кодовых баз: память проекта, планирование, выполнение и проверка завершения внутри Codex. Лицензия MIT, основной язык TypeScript, 3865 звёзд.

Смотреть имеет смысл тем, кто уже ведёт длинные задачи в Codex и упирается в обрыв сессии. Из описания следует контур «план, потом проверка», а не обещание, что любая задача закроется сама. Команду установки этот выпуск не повторяет: её надо читать в README на день, когда открываете проект.

claude-agent-acp: Claude Agent SDK в чужом клиенте

agentclientprotocol/claude-agent-acp описан коротко: использовать Claude Agent SDK из любого клиента ACP. ACP здесь Agent Client Protocol. Лицензия Apache-2.0, TypeScript, 2717 звёзд, push 2 ноября 2026.

Практический смысл в стыке. Если редактор или своя оболочка говорит на ACP, агент Claude не обязан жить только в одном фирменном окне. Подходит тем, кто собирает свою среду, а не тем, кому нужен готовый чат без настройки.

uni-api: один формат для нескольких LLM

yym68686/uni-api описан как шлюз управления LLM API. Клиент ходит в один интерфейс формата OpenAI, а сзади могут стоять разные сервисы. В описании на 2 ноября 2026 названы OpenAI, Anthropic, DeepBricks, OpenRouter, Gemini и Vertex. Есть упоминание балансировки. Лицензия Apache-2.0, язык Rust, 1271 звезда.

Это инфраструктура, не чат. Полезно, когда в продукте уже есть клиент под OpenAI, а ключи и модели меняются. Скорость и отказоустойчивость из описания не следуют: их надо мерить на своём трафике.

Entire CLI: сессия агента рядом с коммитом

entireio/cli цепляется к Git и сохраняет сессии ИИ-агента по ходу работы. Сессии индексируются рядом с коммитами, чтобы позже было видно, как именно появился код. Лицензия MIT, язык Go, 5290 звёзд, push 2 ноября 2026.

Это след для команды, где в одном репозитории пишут и люди, и агенты. Карточка не заменяет политику ревью. Она говорит только, что история сессии может лежать рядом с историей коммитов.
