mcode-stack: навыки и чек-листы команды MiniMax Code

Описание MiniMax-AI/mcode-stack: рабочие процессы и навыки, которыми команда MiniMax Code собирает сам MiniMax Code. В README это не сборник «лучших практик», а то, чем пользуются каждый день: как держать планку кода от ИИ, когда отдавать задачу субагенту, сколько ждать длинную команду, как не дать длинной сессии «протухнуть» и что класть в контекст на каждом шаге. Каждый кусок — файл SKILL.md или чек-лист, который ставится в MiniMax Code. Лицензия MIT, язык Python, 540 звёзд, push 6 ноября 2026.

Смотреть тем, кто уже работает с агентом по навыкам и хочет готовый стек от команды продукта, а не абстрактные промпты. Совместимость с Claude Code или Codex в карточке не измерялась: это читают в README репозитория.

rea-video: разбор ролика по кадрам для Claude Code и Codex

JuneYaooo/rea-video описан как навык, который разбирает любое видео покадрово: снято ли вживую, сгенерировано ИИ или собрано кодом, как сделаны титры, склейки и звук, и какой план нужен, чтобы повторить. В бейдже README указаны Claude Code и Codex. Есть README на русском и других языках. Лицензия Apache-2.0, Python, 2181 звезда, push 5 ноября 2026.

Практический смысл — для рекламных роликов и шортов, где нужно понять приём, а не пересказывать сюжет. Качество разбора на вашем материале в этой карточке не проверялось.

herdr-app: десктоп для терминалов и кодинг-агентов

Описание herdrdev/herdr-app короткое: десктоп-приложение Herdr. В README: пространства, вкладки и панели для терминалов и кодинг-агентов; видно, каким агентам нужен ответ; при закрытии окна терминалы продолжают работать. Есть установщики для Linux, macOS (Apple Silicon) и Windows, сайт herdr.dev. Рядом ставится herdr-core. Лицензия Apache-2.0, язык Rust, 2078 звёзд, push 5 ноября 2026.

Это десктоп-клиент. Мобильный PWA Collie для Herdr уже разбирался в вечернем выпуске 5 ноября; здесь другой контур — окно на компьютере. Совместимость со своим набором агентов нужно сверять с актуальным README.

terminal-mac: гостевой macOS для агентов в терминале

govijr/terminal-mac описан как отдельный рабочий стол macOS для computer-use агентов, который смотрят и управляют из терминала. По README гостевая система поднимается через Apple Virtualization на Apple silicon: у гостя свои приложения, файлы и аккаунты, без сессий хоста; курсор и буфер обмена физического Mac агент не трогает. Экран стримится через графику Kitty или iTerm2. Ранний release candidate, нужен macOS 14+. Лицензия MIT, Swift, 1978 звёзд, push 5 ноября 2026.

Репозиторий создан 3 ноября 2026. Это песочница под агента, а не замена основного Mac: гость ест CPU, память и диск хоста. На Intel Mac из README путь не описан.
