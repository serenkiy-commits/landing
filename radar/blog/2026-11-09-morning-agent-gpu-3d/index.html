Pinky: агент управляет телефоном, а рискованные шаги ждут человека

DIYgod/pinky в описании репозитория даёт AI-агентам пользоваться телефоном, с человеком в контуре. По README это приложение для macOS, Windows и Linux: через MCP любой агент — Claude Code, Claude Desktop, Codex, Cursor или скрипт — управляет настоящим iPhone или Android, а человек смотрит на компьютере, одобряет рискованные шаги, перехватывает управление и потом просматривает запись. Одобрения, по README, держит шлюз Pinky, а не инструкция агенту. Платежи по умолчанию ждут клика; в настройках можно поставить на ожидание отправку сообщений, заказы, удаления, звонки и другие действия. Банковские приложения, кошельки и менеджеры паролей агенту по умолчанию не видны, в поля пароля и одноразового кода он не печатает. На Android 13 и новее агент работает на скрытом втором экране. Android поддерживается с 10-й по 17-ю версию, iPhone — с iOS 17.4; ниже iOS 27 нужен вспомогательный WebDriverAgent, который ставится из Xcode. Лицензия Apache-2.0, основной язык Go, 912 звёзд, push 9 ноября 2026.

Смотреть тем, кто хочет отдать агенту телефон, но оставить за собой платежи и отправку. Оговорки из README: установщик для Windows пока не подписан, и SmartScreen может его остановить; работа на iPhone ниже iOS 27 авторами пока не проверялась на физическом телефоне. Запись шагов и скриншоты, по README, остаются на компьютере. Этот выпуск приложение не устанавливал.

sand3d: 3D-модели короткими программами для LLM

Sandflow-ai/sand3d — по описанию 3D-моделирование на Python, сделанное под LLM. README описывает библиотеку поверх Blender bpy: объект пишется как короткая программа из профилей, тел, правок, шарниров и сборок, а детали, рёбра и грани вызываются по имени, без вычисленных вручную координат. Один и тот же код, по README, собирает один и тот же меш бит в бит. Весь API, по словам авторов, укладывается примерно в 3600 токенов и рассчитан на то, чтобы положить его в системный промпт модели. Экспорт — GLB, URDF, USDA, OBJ и STL: от веба и игровых движков до ROS, MuJoCo и Isaac. Установка — pip install sand3d; нужен Python 3.13 или 3.11, для 3.12 колеса bpy нет. Сайт: sandflow.ai/sand3d. Лицензия Apache-2.0, 1440 звёзд, push 6 ноября 2026.

Подходит, когда модель должна выдавать 3D-объект кодом, который потом читает человек: предметы, детали с шарнирами, модели для симуляторов роботов. Сравнение по токенам с Blender Python, CadQuery и FeatureScript — цифры авторов из README; в этом выпуске оно не повторялось.

vork: headless-движок 3D и VFX, где сцену пишет агент

voyager-so/vork в описании — headless-движок 3D и VFX для агентов, research preview. По README агент пишет сцену кодом, рендерит её, смотрит на картинку и правит код — без редактора, который пришлось бы кликать. Движок на Rust и Slang, рендер на GPU через Vulkan и Metal; видеомодель для этого не нужна. Работа начинается с vork init, vork render и vork help. Для рендера README требует Apple Silicon или NVIDIA с поддержкой ray queries в Vulkan; писать сцены и читать справку можно без GPU, на своей Linux-машине с NVIDIA предлагается Docker-рантайм. Сайт: voyager.so/vork. Основной язык Rust, 1151 звезда, push 7 ноября 2026.

Главная оговорка — лицензия. Это не open source: текст «vork Preview License» называет проект source-available и разрешает бесплатное использование, в том числе коммерческое, на время research preview. Что будет после превью, в README не расписано. npm-пакеты, по README, пока кандидаты и не опубликованы. Этот выпуск движок не запускал.

gputaskman: что именно занимает видеопамять

shanselman/gputaskman — диспетчер задач GPU для Windows, Linux и WSL: видеопамять и активность по процессам и разбор того, что загрузила LLM — веса модели, KV-кэш. README формулирует идею как htop для того, что внутри видеокарты: не только сколько памяти занято, но чем — весами, кэшем, браузером или композитором рабочего стола. Это терминальный интерфейс. NVIDIA поддерживается везде, AMD — на Windows и нативном Linux, есть раздел про macOS на Apple Silicon. Данные берутся из NVML, который идёт с драйвером NVIDIA, и из AMD ADL; ключ API, сессия администратора и загрузка моделей, по README, не нужны. Установка — uv tool install gputaskman или pipx install gputaskman, для Windows есть портативные ZIP. Лицензия MIT, Python, 1089 звёзд, push 9 ноября 2026.

Смотреть тем, кто гоняет локальные модели и не понимает, куда ушла видеопамять. Оговорка прямо в README: ПО ранее и экспериментальное, счётчики устройства и процессов — измерения, а классификация и разбивка по GGUF — оценки. Дамп видеопамяти инструмент не делает. Для контейнеров и арендованных GPU README описывает отдельный шаг сопоставления процессов.

Что из этого следует
