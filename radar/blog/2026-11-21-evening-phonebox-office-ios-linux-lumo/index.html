К агенту можно подключить несколько телефонов со своими раскладками или переключать один телефон между спаренными компьютерами. Переводы README лежат рядом с английским, среди них русский: английский и двенадцать ссылок на другие языки совпадают с «13 languages» в описании.

Приложение оборачивает веб-приложение Lumo в оболочку Tauri и даёт ему доступ к компьютеру и инструментам после подтверждения человека. Что README перечисляет. Подтверждения: каждый инструмент стоит в одном из трёх режимов — выполнять сразу, спрашивать или выключить. Режим «спрашивать» ждёт ответа, прежде чем инструмент запустится. Быстрый вопрос: глобальное сочетание клавиш открывает окно поиска из любого места. Запросы по расписанию. Секреты: токены OAuth, ключи API и учётные данные MCP лежат в связке ключей операционной системы, служба me.proton.lumo-app. Вход — в своём браузере, чтобы работали ключи безопасности и passkey: README объясняет это тем, что WKWebView не отдаёт WebAuthn. Сессия возвращается в вебвью по протоколу session-fork Proton, код — в src-tauri/src/browser_login.rs. Обновления подписаны на всех платформах, которые README перечисляет.

Само веб-приложение в этом репозитории не лежит. README пишет, что оно живёт в монорепозитории веб-клиентов Proton и загружается по адресу LUMO_URL. Мост window.LumoConnectors связывает страницу с TypeScript в webview/bridges/connectors, дальше Tauri IPC идёт в ядро на Rust в src-tauri/src. Ядро держит реестр инструментов, коннекторы, связку ключей, шлюз подтверждений, область учётной записи и обновлятор. Команды перечислены в src-tauri/permissions/*.toml и выданы в src-tauri/capabilities/default.json. Контракт моста разделён на два репозитория: webview/bridges/connectors.ts и desktop-tools.ts веб-приложения должны совпадать. Коннекторы регистрируются при старте в ToolRegistry и видны веб-приложению как инструменты формата OpenAI с именем {connector_id}__{tool_name}. README перечисляет filesystem (поиск, чтение, запись и правка внутри выданных корней), bash, browser (страницы из сети), proton_mail через Proton Mail Bridge, luminance через публичный API v2 напрямую, произвольные mcp-{id}, отдельный mcp-zendesk и mcp-figma на локальный сервер Figma http://127.0.0.1:3845/mcp. Часть серверов каталога README называет экспериментальными и прячет за флагом. echo — фикстура сквозных тестов, только при LUMO_E2E_TESTING. Инструмент в режиме «спрашивать» останавливает выполнение, шлёт запрос в вебвью и ждёт ответ или таймаут.

Кому: тому, кто хочет читать или собирать десктоп-оболочку Lumo. Веб-ассистент при этом остаётся удалённой страницей Proton, а не файлами этого репозитория. Пакеты по README: macOS — универсальный .dmg для Apple silicon и Intel; Windows — .msi и установщик -setup.exe; Linux — .deb и .rpm для Ubuntu 24.04+ и Fedora 40+. Для разработки README просит Node.js 22, стабильный Rust редакции 2021 и зависимости Tauri для своей системы: WebKitGTK на Linux, WebView2 на Windows. npm install и npm run dev по умолчанию грузят веб-приложение с https://lumo.proton.dev, это локальная копия веб-клиентов Proton. Против боевого адреса: LUMO_URL=https://lumo.proton.me npm run dev. Без входа приложением, по README, не воспользоваться. Изменения Rust перезапускают приложение. Изменения TypeScript сами не подхватываются: отдельного сервера разработки для фронтенда нет, esbuild отрабатывает один раз при старте, после правки .ts README просит npm run build:webview и перезагрузку окна. Скрипты, которые вставляются в страницу, требуют перезапуска npm run dev. Проверки: npm run typecheck и cargo test --manifest-path src-tauri/Cargo.toml --features test-utils. Сквозные тесты — ./e2e/run.sh в контейнере Linux, потому что WebKitGTK отдаёт WebDriver; нужна копия веб-клиентов Proton рядом с проектом или в CLIENTS_DIR. Сборка: на macOS APPLE_SIGNING_IDENTITY="-" npm run build даёт приложение с ad-hoc подписью, на Linux и Windows хватает npm run build. Пакеты попадают в src-tauri/target/<target>/release/bundle/. Исполняемый файл называется lumo-desktop (lumo-desktop.exe на Windows), отображаемое имя — Lumo. Настройки: на macOS ~/Library/Application Support/me.proton.lumo-app/, на Windows %APPDATA%\me.proton.lumo-app\, на Linux ~/.config/me.proton.lumo-app/. Снятие локальной установки и её данных — ./src-tauri/scripts/uninstall.sh. Сборки релизов, подпись и публикацию README относит к внутреннему CI Proton, файл RELEASING.md во внутреннем репозитории. Лицензия в снимке API и в README — GPL-3.0. Язык по снимку API — Rust. Темы снимка: ai, privacy, productivity.
