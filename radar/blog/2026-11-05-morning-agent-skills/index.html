answer-me-with-html: одна HTML-страница на сложный вопрос

Описание QingYunA/answer-me-with-html: навык агента, который на сложный вопрос отвечает одной HTML-страницей, которую можно читать. В бейдже README как совместимые указаны Claude Code, Codex, Cursor, OpenCode, Pi и DeepSeek Harness. В шапке README — один файл и работа офлайн. В тексте есть режим always-on и пояснительные видео. Сайт проекта: answer-me-with-html.com. Лицензия MIT, язык JavaScript, 5304 звезды, push 5 ноября 2026.

Автор README заявляет, что модель пишет примерно 1/8 токенов от ручного написания HTML. В таблице README короткий вопрос в одну строку остаётся коротким ответом, без страницы.

superlite: одно утверждение плана, дальше код

iha2/superlite описан как быстрый контур для Claude Code: одно утверждение плана, параллельные волны, маршрутизация моделей. По README это плагин Claude Code. План утверждают один раз, дальше собирается код. Рядом в README описан второй режим: оркестратор планирует и раздаёт задачи сам. В бейдже README параллельные агенты помечены «up to 18». В тексте README эта цифра отнесена к замеру run k1, а потолок одновременно запущенных задач указан как 10. Задачи раздаются моделям разных уровней: для задач названы Sonnet и Haiku, финальное ревью — отдельный свежий ревьюер. Режимы в README: новый MVP, фича в существующем коде, отладка, малые правки, ревью. Каждая сессия открывает ветку superlite/sessions/<topic> или параллельный worktree, если другой запуск ещё идёт. Лицензия MIT, Python, 248 звёзд, push 5 ноября 2026.

Смотреть тем, кто хочет отдать Claude Code план и получить ветку с кодом. Как очередь агентов ведёт себя на своём репозитории, в этой карточке не измерено: это читают в README и проверяют у себя.

Описание WenyuChiou/agent-board: видно, что делает каждый агент для кода, а то, что ждёт вашего ответа, стоит сверху. Это плагин Claude Code. В описании он также следит за Codex, Gemini CLI, Cursor, OpenCode, Grok Build, Hermes Agent и Muse Code. На npm есть пакет @wenyuchiou/agent-board. Лицензия MIT, TypeScript, 46 звёзд, push 5 ноября 2026.

В подписи к обложке README сказано: статус «Accepted» не означает доставку. Доставкой считается подтверждение от сессии. Подтверждение в этой подписи — о получении, а не о том, что работа закончена. 46 звёзд — счётчик на дату замера.
