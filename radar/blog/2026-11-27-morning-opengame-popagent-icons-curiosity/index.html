OpenGame: шаблоны, ремикс и MCP

nexu-io/opengame в описании API — Super Game Agent: «the Unity & Unreal for AI agents», больше 100 вирусных игр для ремикса и студия, которая собирает 3D и мини-игры и публикует их в WeChat, Douyin, TikTok, Telegram, itch.io и другие площадки. README называет проект открытой студией, которая подключает уже стоящего локального агента, и пишет о 25 готовых играбельных шаблонах в templates/games/: HTML5, Canvas и Three.js, с обложками и метаданными. Таблица README перечисляет эти 25 по именам, от Castle Crush до Tilt Temple. Стена агентов подписана как 22 локальных клиента; описание API говорит о «20+». Бейджи README называют DeepSeek TUI, Claude Code, Codex, Cursor, Gemini CLI, WorkBuddy и ещё шестнадцать имён из того же списка. Запуск README описывает так: Git, Git LFS, npm и Node.js 22.18 или новее; CI фиксирует Node.js 26.11.1. Клон с --depth 1, затем npm ci, npm run build:studio и npm start. Каталог открывается сразу, файлы шаблона скачиваются при первом запуске или ремиксе; Tidebreaker README называет работающим офлайн. Скилл ставится командой npx skills add https://github.com/nexu-io/opengame/tree/skills --skill opengame. Локальный MCP — stdio, двенадцать инструментов openmotion_game_*: черновик игры, чтение и запись файлов, проверка логики на 50 тиках, три сценария симуляции, плейтест в headless Chrome, обложка 1280×720, трейлер и публикация в локальный каталог. Запись файлов README ограничивает сотней текстовых файлов и 8 МиБ на одну свою игру. Ключи моделей README держит в Model Gateway, отдельно от исходников игры; без ключей остаются процедурные спрайты, Web Audio и геометрия Three.js. В таблице публикации колонка «уже доступно» — локальный каталог Studio, веб-ссылка через OpenDesign Cloud, режим 9:16 playable ad и выгрузка самодостаточного HTML5/JS для ручной упаковки. Направляемая публикация на WeChat Mini Games, Douyin, TikTok, Xiaohongshu, itch.io, Poki и CrazyGames стоит в колонке «Roadmap (In Progress)». Telegram в этой колонке README не назван. PopAgent: интерфейс к своим агентам

duzhenxun/pop-agent в описании API — локальный веб-интерфейс к уже установленным кодинг-агентам: поток рассуждений, правка по ходу хода, модели и инструменты. Сессии остаются файлами самого движка, без базы и без аккаунта. README повторяет это тремя правилами: сессии — JSONL и треды движка; кнопки скрываются, если у движка нет такой возможности; по умолчанию сервер слушает только 127.0.0.1. Доступ снаружи README описывает как явный -H 0.0.0.0 и пароль, заданный на самой машине: удалённый клиент пароль создать не может. Движки в таблице README: pi через нативный SDK, он же по умолчанию; Codex через app-server; DeepSeek Harness и opencode через ACP; Claude Code через адаптер claude-code-acp. В API DeepSeek Harness назван DSH. У pi в таблице есть нативный steering и панель субагентов; у остальных steering README описывает как остановку и повторную отправку, панели субагентов нет. Рядом README описывает голос, задачи по cron, управление Mac через дерево accessibility, холст шагов, Web Push без стороннего сервиса и раскладку для телефона. Распознавание речи по умолчанию — локальное на macOS, SFSpeechRecognizer, системный голос; переключение на edge, свой kokoro или qwen3 README даёт отдельно. У задач по расписанию запись в файлы по умолчанию выключена, пока на задаче не отмечено разрешение менять файлы. Поля паролей управление компьютером не заполняет, системную аутентификацию и приложения из System Settings README оставляет закрытыми. Установка: .dmg для macOS на Apple Silicon, рантайм внутри приложения; иначе npm -g install pop-agent и Node 22.19 или новее. На Linux встроенный терминал собирает node-pty и просит make, g++ и python3. Пакет macOS README называет подписанным ad-hoc, без подписи Apple Developer. Лицензия MIT, язык в снимке — TypeScript. generate-icons: набор иконок под дизайн-систему

sergiobanhos/generate-icons в описании API — скилл агента, который рисует оригинальную библиотеку иконок под дизайн-систему проекта: React, Vue, Svelte, React Native или SVG. README раскладывает ход так: scripts/scan_design_system.py читает токены, тему, шрифты и уже стоящие иконки; агент спрашивает только то, что скан не закрыл; пишет icon-style.json и показывает, из какого файла взято каждое решение; scripts/inventory.py собирает кандидатов из меню, маршрутов, enum и эмодзи. Сначала образец из 6–8 иконок рядом с текущими, в светлой и тёмной теме, в макете сайдбара, кнопок и пустого состояния. После подтверждения — полный набор, проверка scripts/validate.py и сборка scripts/build.py. На выходе README называет компоненты под стек, каталог svg/, sprite.svg, icons.css, manifest.json, catalog.html и README. Восемь стартовых стилей README даёт проекту без своей системы: outline, solid, duotone, soft 3D gradient, glossy app icon, flat color, pixel и hand-drawn. README прямо пишет, что пути из Lucide, Heroicons, Phosphor, Material и чужие логотипы скилл не копирует, а нарисованное относит к вам. Установка — git clone в ~/.claude/skills/generate-icons или в .claude/skills/ одного проекта; другим агентам README предлагает положить папку туда, где они читают SKILL.md. Нужен Python 3.8 или новее, только стандартная библиотека; headless-браузер README называет необязательным. В examples/ лежит готовая библиотека из 12 иконок в двух стилях для React. README публикует скриншот меню CvPorVaga до и после; этот выпуск страницу не открывал. Лицензия MIT, язык в снимке — Python. Weaponized Curiosity: исследование с лимитом

AyushRajSinghParihar/weaponized-curiosity в описании API — переносимый скилл агента для исследований по источникам, экспериментов и ограниченной оптимизации. README ставит его командой npx skills add AyushRajSinghParihar/weaponized-curiosity --skill weaponized-curiosity и называет Codex и Claude Code: вызов $weaponized-curiosity и /weaponized-curiosity. Ручная установка README сводит к Git. Режимы в таблице README: Quick — проверить утверждение, сравнить два варианта или сверить план с жёстким требованием; Deep — разобрать противоречивые источники, агент может разделить работу на четырёх независимых воркеров там, где это поддержано, и сравнить, что они нашли; Extreme — больше времени на разбор источников, конкурирующие объяснения и повтор; Autoresearch — улучшать то, что можно измерить, с целью и лимитом попыток. Лимиты README принимает и словами, и ключами вроде searches=12 experiments=2 minutes=10; experiments=0 оставляет исследование без опытов. Короткий ответ README описывает как вывод и доказательства за ним. При близком выборе агент должен сказать, что перевернёт рекомендацию и как это проверить дешевле всего. Длинные прогоны могут сохранить источники, гипотезы, результаты проб и чекпоинт в .research/<run-id>/. Скилл пользуется инструментами и правами уже установленного агента; если инструмента нет, отчёт должен назвать, что осталось непроверенным. В примере оптимизации README пишет, что индексация всех значений была примерно в 41 раз быстрее на свежих входах и не прошла лимит памяти, а замороженный кандидат индексировал только пробы, занял около 10 КиБ временного выделения Python и те же проверки прошёл. Этот выпуск замер не повторял. Лицензия MIT, язык в снимке — Python.
