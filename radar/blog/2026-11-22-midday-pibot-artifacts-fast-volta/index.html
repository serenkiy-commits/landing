PiBot: локальная команда агентов

w01fb0ss/PiBot — десктопное приложение, в котором именованные боты работают на вашем компьютере: личный чат или группа с координатором, который планирует шаги и раздаёт их участникам. По README боты запускают команды, правят файлы, ходят в браузер и пользуются компьютером, а рискованный шаг ждёт подтверждения. Чаты, файлы, память и ключи остаются на машине; к выбранному провайдеру модели уходят только отправленные промпты. Модели — локально через Ollama, через OpenRouter, своими ключами или поддерживаемым входом по подписке. Команды идут через песочницу, действия пишутся в журнал. Платформы в README: macOS 13 и новее, Windows 10/11, 64-bit Linux, отдельно — приложение для Android. Ядро — агент pi, подключённый как npm-зависимость. Сборка из исходников: Node из файла .nvmrc и pnpm 12. Кому: тем, кто хочет команду агентов на своём компьютере и подтверждение опасных действий. open-artifact: артефакты агента как файлы

JimLiu/open-artifact — локальный формат, в котором кодовый агент собирает не только текст в чате, а вещи, которые можно открыть и поправить: слайды, макет интерфейса, дизайн-систему, доску, таблицу, дашборд, документ или короткий ролик. Агент пишет папку обычных файлов, локальная страница открывает редактор, комментарии командой «Send to agent» возвращаются в сессию. В README: без аккаунта и без привязки к одной модели; раньше проект назывался baoyu-design, старый адрес перенаправляет сюда. Плагины перечислены для Claude Code, Codex, Cursor, GitHub Copilot, Antigravity, ChatGPT и DeepSeek Harness; для установки из релиза указан Node.js 22.18+. Кому: тем, кто просит агента сделать слайды, макет или документ и хочет править результат у себя на диске. fast-anything: в Rust только медленные функции

EL4CTEO/fast-anything — CLI, который профилирует приложение и отдаёт агенту перенос только горячих функций в Rust, а не всего проекта. В README языки: Python 3.10+, JavaScript и TypeScript на Node 22+, Ruby 3.3+, Java 22+, Go 1.22+, PHP 8.1+, C и C++. Порт — отдельный маленький крейт; включение после сверки с записанными вызовами: значения должны совпасть, ошибки — там же, где у исходной функции, а сам вызов не должен стать медленнее. Обратно выключается той же командой, переменная FAST_ANYTHING_DISABLE=1 запускает исходный код. Агент в README: Claude Code, Codex или любая команда, которая читает промпт из stdin; есть встроенный MCP-сервер и скилл. Установка из README: npm i -g @el4cteo/fast-anything или cargo install fast-anything, порты собирает локальный Rust. Кому: тем, у кого тормозит кусок на одном из этих языков и кто не хочет переписывать приложение целиком. volta-forever: CUDA 13 на Tesla V100

nbald/volta-forever — прослойка перед библиотекой драйвера NVIDIA. По README CUDA 13 больше не собирает код для Volta (sm_70), и такая программа на Tesla V100 останавливается; volta-forever при загрузке переписывает GPU-код, саму программу и драйвер не меняет. Команда vf ставится перед запуском, чтобы немодифицированные программы CUDA 13 — колёса PyTorch, vLLM, SGLang, llama.cpp — шли на V100. Нужны карта Tesla V100, драйвер NVIDIA ветки 580 и Linux x86-64 с glibc 2.34 или новее (в README названы Ubuntu 22.04, Debian 12 и более новые). Автор пишет, что проект не от NVIDIA и NVIDIA его не одобряла; чего запустить не может, отказывается с причиной, ограничения собраны в LIMITS.md. Кому: тем, у кого осталась Tesla V100 и кто хочет гонять актуальные сборки CUDA 13 без перекомпиляции под Volta.
