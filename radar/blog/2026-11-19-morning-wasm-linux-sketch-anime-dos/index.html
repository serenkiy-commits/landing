Unkernel: Linux в WebAssembly

pithings/unkernel в описании GitHub — «A real Linux kernel, compiled to WebAssembly. It boots to a shell in less than a second.» Домашняя страница — unkernel.dev. README описывает Linux 7.x, собранный одним wasm-модулем с настоящим MMU. Ядро — системные вызовы, планировщик, управление памятью, ext4 и TCP/IP — это скомпилированный код, не эмуляция. Пользовательские программы — немодифицированные бинарники Linux для riscv64, их исполняет JIT, поэтому пакеты Alpine и Ubuntu, по README, запускаются как есть. На странице в браузере README называет оболочку, пакетный менеджер, постоянный диск, доступ в интернет и экран со звуком. Всё выполняется на устройстве, без сервера. Есть CLI и JavaScript SDK.

Кому: тем, кто хочет открыть в браузере оболочку Linux, собранного в WebAssembly, и запускать немодифицированные пакеты Alpine и Ubuntu. Как попробовать: страница unkernel.dev — README относит к ней оболочку, пакетный менеджер, постоянный диск, интернет и экран со звуком. Отдельно README называет CLI и JavaScript SDK. Фразу «меньше секунды до оболочки» выпуск берёт из описания GitHub и сам не замерял. Язык по снимку API — TypeScript, лицензия GPL-2.0. 468 звёзд на 19.11.2026, ~06:25 МСК, последний push 17.11.2026. Stick Scene: скетч-анимации для агентов

nilbuild/stick-scene в описании GitHub — «Skill to draw stick figure animated visuals». Домашняя страница — kamran.fyi/stick-scene. README описывает навык агента: он рисует небольшие сцены из человечков, которые показывают, что делает продукт. Каждая сцена — один <canvas>, без зависимостей. Сцена стоит в покое и проигрывает действие, когда блок попадает в зону просмотра, по клику или при наведении. Установка из README: npx skills add nilbuild/stick-scene, затем /stick-scene и текст того, что показать. Дальше, по README, агент читает проект, предлагает 2–3 идеи, пишет сцену, рендерит её кадр за кадром, чтобы проверить наложения, и добавляет сцену на страницу. Правки просят обычными словами: медленнее, зациклить, цвет бренда.

Кому: тем, кто хочет, чтобы агент добавил на страницу короткую сцену из человечков про свой продукт. Как попробовать: команда npx skills add nilbuild/stick-scene, затем /stick-scene с описанием сцены. Страница навыка — kamran.fyi/stick-scene. Tiny-2.1: LLM для DOS

WollyMonjac/Tiny-2.1 в описании GitHub — «Language model for DOS that fits on a floppy disk». README описывает маленькую вопросно-ответную трансформер-модель, написанную на Turbo C 2.0: она запускается на Pentium или 486DX под обычным DOS. В README: 367 000 параметров, 4 слоя, ширина 96, ответ по буквам. Веса 8-битные, всего 380 КБ. Нужно около 540 КБ свободной conventional memory. Обучена примерно на 3500 фактах и вне их, по README, уверенно выдумывает. Набор для обучения — на Python и PyTorch, по README хватает CPU. Свои факты можно добавить. Это эксперимент и любопытство, не практический инструмент для ответов.

Кому: тем, кто хочет посмотреть на маленькую вопросно-ответную модель под DOS, а не получить рабочий помощник. Как попробовать по README: программа на Turbo C 2.0 для Pentium или 486DX под обычным DOS, ей нужно около 540 КБ свободной conventional memory. Набор обучения — Python и PyTorch, CPU по README достаточно, свои факты можно добавить. Отдельной домашней страницы в снимке API нет.
