agent-shared-facts: одна опубликованная запись на всех устройствах

siwen-121/agent-shared-facts в описании GitHub — reference implementation для агентов: общие проверенные факты между устройствами через Git и read-only MCP. Английский раздел README говорит о reviewed records. У каждой записи опубликованная версия принадлежит одной Git-ветке. Агент может подготовить кандидата офлайн, сверить его после повторного подключения, отдать на ревью и подтвердить публикацию, забрав слитую запись из другого клона. Китайский раздел README разделяет три состояния: офлайн-черновик, кандидат на ревью и уже действующую запись. У общей записи на заданной ветке фиксированные ID и путь к файлу. Когда агент читает запись, он получает и commit SHA. Кандидат проходит сверку, ревью и слияние. Второе устройство подтверждает публикацию только после того, как прочитает с upstream фактическое содержимое.

Старт в README: на Windows .\setup.cmd, на macOS и Linux sh ./setup.sh. Нужны Git и Python 3.12 или новее. Для приёмки MCP README просит виртуальное окружение и python -m pip install -r requirements-mcp.txt, затем python -m unittest discover -s tests -v. Тесты, по README, используют временный Git-upstream, два независимых клона и синтетические записи. Аккаунт GitHub, API модели, домен и туннель для этого прогона не нужны. Деплой по умолчанию — свой приватный Git-репозиторий и локальные инструменты чтения и записи. Клиенту с MCP можно добавить сервис, который китайский раздел называет read-only. Английский раздел описывает необязательный MCP-адаптер: он отдаёт записи из allowlist через stdio или аутентифицированный Streamable HTTP. В оглавлении README есть страница подключения для Codex, Claude Code, Antigravity, Kimi, DeepSeek, Muse и браузера. Публичный репозиторий хранит программу, процесс и синтетические примеры. Настоящее развёртывание README отправляет в свой репозиторий с общими данными. Исходные файлы исследования, личные данные и учётные секреты остаются в разрешённых местах. На общую сторону попадают только одобренные конспекты и прослеживаемые ID доказательств. Лицензия MIT.
