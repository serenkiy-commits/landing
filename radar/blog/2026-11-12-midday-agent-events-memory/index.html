pine: агент просыпается на событие

pmndrs/pine в описании GitHub — реактивная обвязка для агентов. README ставит рядом обычный чат («сделай это») и подписку: агент смотрит папку, команду, сайт, FTP, вебхук и другие источники и сам реагирует. Чат, задачи, код и оркестрация в README тоже есть. Память у агента заявлена как базовая часть. Пакет — @pmndrs/pine, установка npm install -g @pmndrs/pine.

Источник события в README — файл *.ts со схемой. Агенту говорят, на что подписаться, и он подписывается сам: пример из README — следить за ~/documents/scans и на каждый новый файл вытащить сводку и платёжные реквизиты, если они есть. Конфиги руками README предлагает не править: главный агент создаёт агентов, MCP, источники, скиллы и расписания своими вызовами. Встроенный MCP с индексом BM25 отдаёт справку по API по запросу, чтобы документация не лежала в контексте целиком. Интерфейс — терминал с вкладками, кнопками, картинками, видео и перетаскиванием. README пишет, что это работает в терминалах с протоколом Kitty, например Ghostty, а для старых есть запасной путь. В комплекте: computer use, браузер, инструменты для кода, диффы и git. Агент может делегировать и поднимать субагентов параллельно. Закреплённая вкладка хранит агента и его задачу.

Быстрый старт в README: pine init ставит браузер для веб-инструментов и каталог ~/.pine. На Linux там же поднимается песочница, перед установкой пакетов программа показывает список и спрашивает один раз. pine check проверяет конфигурацию и печатает замечания по безопасности, если что-то открыто. pine открывает интерфейс и сам поднимает демон, если его нет. pine start оставляет демон без окна, чтобы агенты продолжали слушать события. Модели: pine login anthropic и pine login openai-codex садятся на подписку Claude или ChatGPT, pine login opencode-go — отдельный вход. Свой сервер (llama.cpp, vLLM, LM Studio) добавляется адресом, в README пример pine model add studio http://127.0.0.1:8080, переключение в интерфейсе — /model. pine . открывает проект в текущей папке.

Платформы в README: macOS и Linux. Для Windows прямо сказано, что можно пробовать Docker, и что полный набор того, что нужно для Windows, ещё открыт. Контейнеру в примере README выдают SYS_ADMIN, NET_ADMIN, seccomp=unconfined и apparmor=unconfined: песочница агента создаёт пространства имён и свой loopback. Страница docs/references/security.md делит вход на owner и untrusted. Событие без подтверждённого владельца, по этой странице, запускается в своём сеансе и с профилем только на чтение: read, grep, find, ls, без shell, записи, MCP, делегирования и субагентов. Telegram слышит только спаренный аккаунт или список allow. Control API по умолчанию на loopback и с bearer-токеном. Вебхук в описании имеет секрет, если не включён "open": true.

bookleme: книга компилируется в скилл

bookleme/bookleme в описании GitHub — «读了么», BookLeme: книга компилируется в Agent Skill. В описании названы два движка, сменные плагины жанра и проверка, что цитата совпадает с текстом. README на китайском, рядом есть README.en.md. Бейдж README перечисляет форматы: PDF, EPUB, DOCX, MD, HTML, RTF, MOBI. Ядро, по README, на стандартной библиотеке Python 3.9 и новее, без сторонних зависимостей. Запуск из клона: python3 -m bookleme.

README делит результат на два вида. knowledge_pack — справочник: указатель тем, куски, которые подгружаются по запросу, и список источников. behavior_skill — ход разговора: роль, жёсткие ограничения, конечный автомат, именованный формат ответа, антипаттерны. Встроенные плагины: coach_dialogue (коуч, вопрос за вопросом, вывод остаётся за человеком) и knowledge_reference (справка по рамкам; если в книге этого нет, скилл должен отказаться). professional_analysis и decision_checklist в таблице README помечены как ещё не сделанные, этап M4. Свой жанр — один файл в bookleme/plugins/user/. Плагин без автомата, контракта ответа, ограничений, антипаттернов, калибровки тона, профиля авторского права, трёх–пяти китайских слов-триггеров и хотя бы одного отрицательного примера для оценки README отказывается загружать.

Конвейер в README — стадии S0–S9. Извлечение и китайская нарезка идут детерминированным Python и не ждут заголовка «Chapter N». Маршрут жанра смотрит на 12 признаков. Два движка делят промежуточное представление и расходятся на стадии отрисовки, так что книгу не читают дважды. На стадии извлечения способностей README допускает необязательный LLM-экстрактор с OpenAI-совместимым API: цитата всю жизнь сверяется с текстом буквально, а если ключа нет, остаётся детерминированный путь. Установка в «настоящий» каталог скиллов выключена, пока не передан --install.

Авторское право в README отделено от лицензии кода. MIT покрывает конвертер. Книга и получившийся из неё скилл под MIT не попадают. Шесть жёстких ворот, и при любой неудаче результат не ставится и не публикуется: одна цитата не длиннее 150 знаков и находится в тексте буквально; доля цитат не выше 0,03; подряд скопировано не больше 150 знаков; перекрытие 13-знаковых шинглов не выше 0,10; в продукте нет полного текста и нарезок; флаг contains_original_text равен false. Скилл по чужой книге по умолчанию приватный. Публичная раздача требует явных флагов --public --confirm-public PUBLISH и поля прав --user-rights. README публикует таблицу из семи метрик по одному прогону китайской рукописи. Этот выпуск тот прогон не повторял и цифры оттуда не переносит.

maxagent: одна полка опыта на нескольких агентов

vzroslieigry/maxagent в описании GitHub — опыт для ИИ-агентов. Хуки заставляют Claude Code, Codex, Antigravity и OpenClaw вспоминать и записывать то, что уже сработало. Рядом пакет maxagent-bridge: MCP ведёт ваш собственный Chrome, с вашим профилем и вашими входами, через небольшое расширение. README есть и на русском, файл README.ru.md. Страница пакета — npmjs.com/package/maxagent.

Единица опыта в README — короткий проверенный рецепт, «атом». Рабочая папка по умолчанию ~/maxagent: AGENTS.md, experience/, projects/, sync.md, inbox/. Обновление пакета эти файлы не перезаписывает. Мастер npx maxagent init требует Node.js 18 и новее. На установке npm скрипты не запускаются: тяжёлое скачивается после отдельного согласия. Мастер находит установленных агентов, дописывает короткий помеченный блок в их общие правила и ставит хуки. Свои правила остаются, перед правкой файл копируется. Один вопрос решает, ставить ли мост к браузеру, смысловой поиск и общие пачки опыта.

Полок две. Своя, experience/, пишется вашими агентами по формату experience/_spec.md. Свои атомы показываются первыми и могут остановить команду, про которую уже известно, что она ломается. Общая, experience/shared/<pack>/, качается из этого репозитория и только как справка: она видна, когда своей полки не хватило, не больше одного атома на сообщение, и команду не останавливает. Удачный общий атом можно забрать к себе командой npx maxagent experience adopt. Перед установкой пачки клиент сверяет sha256, имена файлов и сам текст: команды вида «скачай и запусти», попытки переписать правила агента, отправку секретов, разрушительные команды и скрытые символы. Любое совпадение отклоняет пачку целиком.

Мост к Chrome в README грузится как распакованное расширение: режим разработчика, Load unpacked, папка. Расширение говорит с локальной программой через Chrome Native Messaging, агенты — через локальный сокет. Открытого порта у моста нет. В описании есть подтверждение на каждого агента, список запрещённых сайтов, журнал действий и кнопка остановки. Смысловой поиск — отдельный шаг npx maxagent vectors, около 270 МБ: модель multilingual-e5-small с закреплённой ревизией и проверкой sha256, библиотеки в ~/.maxagent/vector. Без Python поиск остаётся по словам. Сеть, по таблице README, — это GET публичных файлов: реестр npm, news.json в репозитории, каталог пачек и, только после согласия, Hugging Face и PyPI. updates: false выключает и эти запросы.

Brain4Agent: память сессий без модели на пути поиска

SparkofSpike/Brain4Agent в описании GitHub — модуль памяти для основных агентов, в первую очередь для китайского, японского и корейского. README точнее: долгая память, поиск без модели на основном пути, в ответе улики, а не оценка уверенности. Хранилище — один файл SQLite. Единица выдачи — сессия, строка — реплика. Пакет на PyPI: Brain4Agent. Python 3.11 и новее. pip install Brain4Agent ставит вариант на биграммах без зависимостей. pip install "Brain4Agent[precise]" добавляет словарь jieba, в README это около 20 МБ. Без словаря код остаётся на биграммах.

Запись и запрос в README токенизируются по-разному. В индекс идут биграммы и словарные слова, в запрос — слова, из китайского запроса убираются вопросительные. Для английского README описывает стоп-слова, свёртку словоформ и бонус, если два соседних слова запроса стоят рядом в памяти. Китайский эти три правила не трогают: соседство уже сидит в биграммах. Поиск возвращает факты, а решение об отказе остаётся у вызывающего. corpus_missing — слово вопроса, которого нет ни в одном воспоминании. missing_terms — каких слов не хватило конкретной сессии. term_frequencies — в скольких сессиях слово вообще встречается. related_terms — до пяти слов из верхних сессий, которых в вопросе не было. Необязательный судья Judge.from_env() выключен, пока нет ключа BRAIN4AGENT_JUDGE_KEY. Таймаут судьи README помечает как uncertain, отдельно от not_found.

MCP в README — пять инструментов: b4a_remember сохраняет реплику и возвращает id сессии, b4a_recall ищет и отдаёт corpus_missing и missing_terms, b4a_ask ищет и отвечает за один шаг и прямо говорит, если модель не настроена, b4a_session читает сессию по порядку, b4a_stats отдаёт счётчики. Путь к базе — BRAIN4AGENT_DB. Статус в README: библиотека, CLI и MCP-сервер готовы. В списке того, чего нет: синтез между сессиями, мультимодальность, схема на поле kind, смешение нескольких способов поиска, планировщик напоминаний и забывание по времени. Рядом описаны близкие дубликаты через SimHash: они сообщаются и не сливаются, на путь поиска не встают. README пишет, что проект начался с правки в nhadaututtheky/neural-memory: китайский запрос ничего не находил, потому что регулярное выражение ключевых слов не содержало диапазона иероглифов. В bench/ лежат прогоны, которые README называет воспроизводимыми. Этот выпуск их не запускал и цифры оттуда не переносит.
