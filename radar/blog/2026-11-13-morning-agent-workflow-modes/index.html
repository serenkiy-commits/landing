claude-work-mode: режимы одной сессии

danyuchn/claude-work-mode в описании GitHub — режимы рабочей сессии для Claude Code. Одна слэш-команда переключает auto, out и wrap. README задаёт, что именно слышит модель. auto: внутренние обратимые шаги (локальные файлы, локальные коммиты, тесты) идут без вопроса. Жёсткие стопы — исходящие сообщения, установки, секреты, необратимые удаления, платежи, смена прав и изменения на проде — копятся в список и сообщаются один раз в конце. Вызовы, которые поднимут окно подтверждения, README ставит последними, подряд. out: пакетную работу, которую можно проверить целиком или выборочно (извлечение, классификация, конспекты, ревью), сессия отдаёт фоновому субагенту или внешней CLI, а основная нить проверяет результат. wrap: новые ветки не открываются, закрывается уже открытое, в списке только новые или изменившиеся решения, у каждого метка и рекомендация. Отдельное значение off возвращает обычный режим. Режимы действуют на сессию и сочетаются: в README есть пример /work-mode auto wrap.

Установка в README — /plugin install work-mode --marketplace danyuchn/claude-work-mode. Второй плагин, work-mode-gates, ставит необязательные гейты. README требует Claude Code с плагинами function-hook, версия 2.1.314 или новее. Гейтам нужны bash, jq, git и python3. Значения по умолчанию README называет прямо: напоминание о режимах каждый 8-й промпт, а в режиме out порог сырого вывода за один ход — 20000 символов, после него следующее чтение отказывается, пока модель не делегирует работу или одной строкой не объяснит, зачем читает дальше. Текст режима, по README, уходит модели один раз и повторяется после сжатия контекста или возобновления сессии. Конфиг необязателен. README отдельно пишет, что секреты, force push и выкладку в гейт auto класть не нужно: такие стопы спрашивают в любом режиме.

line-art-animation: линейный SVG, который рисуется вживую

JDhruv14/line-art-animation в описании GitHub — скилл Claude и библиотека TypeScript для анимированных линейных SVG: чернильные фигуры, которые ходят и реагируют, сцены с циклом дня и ночи. README делит репозиторий на три части. SKILL.md и references/ — сам скилл: порядок работы, правила стиля, движение, сцены, проверка, совпадение с референсным роликом и рендер видео. lib/ — четыре модуля TypeScript без зависимостей: ink.ts рисует штрих, gait.ts считает походку и бег, motion.ts держит пружины, маятники и ветер, daynight.ts даёт палитру времени суток. examples/walker/ — одна фигура, examples/village/ — улица со сменой дня и ночи. Всё рисуется в SVG вживую, поэтому картинка остаётся резкой при любом масштабе и отвечает на курсор. В деревне README перечисляет действия в браузере: тащить солнце или луну по небу, двигать курсор, чтобы появился ветер, кликать людей, окна, фонари, колокольчик, кота, птиц и воду.

Установка скилла в README — git clone в ~/.claude/skills/line-art-animation или в .claude/skills/ одного проекта. Для примеров README просит Node 22.18 или новее, затем npm install и npm run dev, адрес http://localhost:5173. Скрипт scripts/capture.ts снимает кадры через headless Chrome по протоколу DevTools, без npm-зависимостей, и сдвигает сцену ровно на один кадр между снимками.
