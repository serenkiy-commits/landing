gridlines: линии, потом отступы

pritamux/gridlines в описании API — скилл агента для прохода по выравниванию: провести направляющие по интерфейсу, найти каждый элемент мимо линии и поправить отступы. README уточняет, что линии вертикальные, а после правки боковые панели, панели инструментов, панели, меню и таблицы сходятся к небольшому набору краёв. Порядок в README: сначала линии, потом сдвиг элементов. Установка — npx skills add pritamux/gridlines или копирование каталога skills/gridlines/ в папку скиллов; для Claude Code README указывает ~/.claude/skills/gridlines/. Пример вызова: /gridlines line up the settings sidebar. Внутри README раскладывает четыре файла. SKILL.md — ход и правила. probe.js работает на странице: меряет края текста, иконок и контролов, рисует направляющие и перечисляет промахи. audit.mjs открывает страницу в headless Chromium, гоняет пробу и сохраняет кадр 2× с направляющими и JSON-отчёт. examples/sidebar.html — боковая панель с четырьмя заложенными промахами, чтобы увидеть отчёт до своего приложения. Скрипту аудита нужен Playwright; README даёт установку в отдельный каталог и переменную PW_DIR. Без скрипта README предлагает вставить probe.js в консоль страницы и вызвать window.__gridlines(). Правила README относит к перерисовке боковой панели Linear у Karri Saarinen и к главе про вёрстку в Apple Human Interface Guidelines. Этот выпуск пробу не запускал. karpo-browser: клики отдельно от плана

machinepulse-ai/karpo-browser в описании API — браузер для ИИ-агентов: модель решений (System 1) делает шаги на странице, агент (System 2) планирует, читает и отвечает. README противопоставляет это схеме, где крупная модель отвечает на каждый клик: здесь план, чтение и ответ остаются крупной модели, а клик, ввод, выбор и прокрутку получает модель решений. На каждом шаге она выбирает одно действие из пронумерованных элементов страницы. Пакет npm — karpo-browser. README просит Node.js 22.18 или новее и локальный Chrome или Chromium (путь — CHROME_PATH) либо уже запущенный браузер (--cdp или BROWSER_CDP_URL). Установка: npm install -g karpo-browser. Команда run отдаёт System 1 одну цель и печатает шаги и итог. Печатать System 1 может только значения из --value: текст, который есть только в цели, не вводится. Секреты (--secret или поле secrets в run()) вводятся по имени и в модель не отправляются; после ввода их поля в том, что читает System 1, закрыты. Протокол System One в README: запрос с полями model, state и questions на SYSTEM1_URL, ответ — объект answers. Адрес по умолчанию — https://openrouter.ai/api/alpha/decisions. В таблице моделей README названы typesafe/jev-1.14, google/gemini-decision-1, openai/gpt-6-luna-decisions и своя модель на том же протоколе. Переменная SYSTEM1_MODEL обязательна, значения по умолчанию у неё нет. Конец прогона README сводит к статусу и странице, до которой дошли: done, needs_from_person, needs_approval (следующий шаг платит, бронирует или необратим), site_cannot, blocked, page_unusable, other_failure, looping, limit, interrupted, failed. Подключение: плагин Claude Code, для Codex — codex mcp add и npx skills add machinepulse-ai/karpo-browser, для другого клиента — stdio-сервер npx -y karpo-browser mcp. README пишет, что Codex спрашивает перед каждым вызовом инструмента, который действует на странице. Есть CLI и типизированный API Browser; README говорит, что runtime-зависимостей нет. MCP открывает только страницы http и https, не файл машины, на которой сервер запущен. Текст страницы README относит к данным: скилл просит System 2 не выполнять инструкции, найденные на странице. Каталог test/controller — необязательный System 2 на публичном интерфейсе библиотеки; README пишет, что пакет npm отдаёт только dist/, поэтому контроллеру нужен клон репозитория. Конфигурацию опубликованных прогонов README описывает флагом --benchmark и отсылает к harness Stagehand на Browserbase Benchmark v2; этот выпуск прогоны не запускал. Код — Apache License 2.0, правообладатель в README — MachinePulse Pte. Ltd., 2026. Исключение README называет для файла evals/stagehand/stagehand.patch: лицензия MIT проекта Stagehand. Язык в снимке — TypeScript. Тем в снимке нет. Домашней страницы в снимке нет.
