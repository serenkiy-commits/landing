cloudroom: облачные сессии для любой coding-обвязки

Описание davidondrej/cloudroom: облачные агенты для любой обвязки. Claude Code, Codex, Pi и OpenCode запускаются своими CLI в изолированных песочницах, у каждой сессии своя Git-ветка, а живая сессия может переезжать между Mac и облаком. По README в репозитории три части: десктоп-приложение, сервис core на Rust (песочница, процесс, очередь, история, восстановление) и набор skills. Есть инструкция по self-host и HTTP API. Сайт: cloudroom.dev. Лицензия Apache-2.0, основной язык TypeScript, 1478 звёзд, push 7 ноября 2026.

Смотреть тем, у кого агенты должны работать, пока ноутбук спит, и кто не хочет привязываться к облаку одного вендора. Как переезд сессии ведёт себя на длинных задачах, в выпуске не проверялось.

box: песочница с запретом по умолчанию

strands-agents/box — открытый движок песочницы для ИИ-агентов от команды Strands. Он сочетает изоляцию средствами ОС с политиками на языке Dogwood: операции, которые проверяет движок, по умолчанию запрещены, разрешение даёт правило permit, а forbid его перекрывает. Секреты подставляются вне процесса агента. Доступ настраивается в box.toml, правила — в policy.dw; обвязку агента можно выбрать любую. Лицензия Apache-2.0, Rust, 499 звёзд, push 7 ноября 2026.

README помечает проект как preview: локальный запуск на Linux ARM64 и macOS на Apple silicon. Для продакшна на x86-серверах это пока не готовое решение — проверьте актуальный список платформ в репозитории.

pomerado: сайт как MCP-интеграция

Pomerado/pomerado описан как способ превратить сайт в API или MCP-интеграцию, включая сайты без собственного API. По README интеграция строится по текстовому описанию задачи, без записи HAR, работает за логином и двухфакторной авторизацией, а затем вызывается агентом детерминированно, без computer use. Для сборки нужен ключ OpenAI и Node 24; сам агент может работать на любой модели. Лицензия MIT, TypeScript, 1569 звёзд, push 7 ноября 2026.

Полезно, когда агенту нужно регулярно ходить в веб-кабинет без API. Надёжность интеграции на конкретном сайте зависит от его вёрстки и защиты — это проверяют на своём стенде.

affectui: React-компоненты для работы агента

flohoeller/affectui — библиотека React-компонентов для того, что делают агенты: деревья агентов, вызовы инструментов, трейсы, передачи задач и подтверждения, плюс обычные элементы интерфейса. Каждый компонент — один файл .tsx со стилями внутри; ставится через shadcn CLI или через MCP-сервер из Claude Code, Cursor или Codex. Часть компонентов вынесена в платную Pro-версию и в репозиторий не входит. Лицензия MIT, TypeScript, 509 звёзд, push 7 ноября 2026. Сайт: affectui.com.

Подходит тем, кто делает свой интерфейс для агентного продукта и не хочет рисовать карточки tool calls с нуля.

Что из этого следует

Два репозитория отвечают на вопрос «где запускать агента»: cloudroom выносит сессии в облако, box ограничивает агента на своей машине. Два других — про связь агента с внешним миром: pomerado подключает сайты через MCP, affectui показывает работу агента человеку. Число звёзд показывает интерес на 7 ноября 2026, не качество кода и не безопасность зависимости.

Лицензии: Apache-2.0 у cloudroom и box, MIT у pomerado и affectui. У affectui и pomerado есть платные облачные или Pro-части — перед внедрением проверьте, что именно входит в открытый код.
