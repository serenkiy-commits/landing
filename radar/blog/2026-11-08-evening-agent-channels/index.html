browse: агент в вашем настоящем браузере

anomalyco/browse в описании репозитория — Let your AI agents use your real browser: an MCP server and a Chromium extension. README описывает MCP-сервер и расширение Chromium: агент открывает и ведёт вкладки через Playwright, делает скриншоты, пишет сетевой трафик и записывает экран. Вкладки агента сгруппированы отдельно; когда нужен вход, подтверждение второго фактора или оплата, агент отдаёт вкладку человеку и ждёт кнопку Continue. В README названы Chrome, Edge, Brave, Arc, Helium, Vivaldi, Opera и Chromium. Установка из README: curl -fsSL https://opencode.ai/browse/install | bash или npx @opencode/browse install. Среди клиентов MCP в README есть OpenCode, Claude Code, Cursor и Codex. Лицензия MIT, основной язык TypeScript, 327 звёзд на 8 ноября, push 8 ноября 2026.

earshot: слух и звук для кодинг-агента

Leonxlnx/earshot в описании репозитория — Ears for coding agents: let AI hear, review and make sound. CPU-only, open source. README описывает локальный CLI, Python API и MCP-сервер: агент получает текстовое описание звукового файла, сравнение с запросом, поиск момента в длинной записи, оценку «живая запись или синтез кодом», таймлайн фильма и карточку запускающего ролика. Отдельно в README есть earshot forge — звук пишется кодом и улучшается прослушиванием — и earshot fit — запись переводится в код синтеза. Банк эффектов и звуковые наборы для фильма, по тексту README, рендерятся без модели и без сети. Установка из README через uv: uv tool install "earshot[mcp] @ git+https://github.com/Leonxlnx/earshot", затем earshot doctor --fetch. MCP для Claude Code добавляется командой из README. Авторы публикуют в документации свои измерения; этот выпуск их стенд не перепроверял и цифры оттуда не повторяет. Лицензия кода MIT, Python, 4253 звезды на 8 ноября, push 6 ноября 2026.

motty: SSH, файлы, экран и помощник в одном окне

t8y2/motty в описании репозитория — SSH, SFTP, port forwarding, VNC/RDP and an AI assistant, MCP in one native window — a Go desktop app built on Viva, with no webview. Это десктопный SSH-клиент: терминал, панель SFTP, проброс портов, удалённый рабочий стол и ИИ-помощник живут в одном окне. В README у помощника два режима: Ask отвечает по видимому терминалу, Agent может выполнять команды в этом терминале с оценкой риска и подтверждением. Опциональный MCP-сервер по умолчанию выключен, слушает только loopback и закрыт токеном; есть и motty mcp-serve по stdio. Хосты в README импортируются из OpenSSH, PuTTY, MobaXterm и других названных форматов. Сборки для macOS, Windows и Linux — со страницы релизов; в README также указаны Homebrew cask и Scoop. Документация: motty.page. Лицензия Apache-2.0, Go, 719 звёзд на 8 ноября, push 8 ноября 2026.

kanzo: общая канбан-доска для людей и агентов

emanuele-em/kanzo в описании репозитория — Self-hosted, sharable kanban for humans and agents. Канбан в браузере и MCP-сервер в одной программе, без аккаунта. По README команда kanzo открывает доску на http://localhost:4242; данные лежат в ~/kanzo. Агенты подключаются через claude mcp add kanzo --scope user -- kanzo mcp или codex mcp add kanzo -- kanzo mcp, либо к адресу http://localhost:4242/mcp. Агент берёт задачу, двигает карточку и пишет комментарии; задачи с меткой Human агенты не трогают. Доску можно открыть другим компьютерам в сети командами kanzo share on и kanzo join или синхронизировать через свой git-репозиторий. Лицензия AGPL-3.0: это стоит учесть, если отдаёте изменённую версию по сети. Основной язык Rust, 1116 звёзд на 8 ноября, push 7 ноября 2026.

Подходит команде, где человек и несколько кодинг-агентов должны видеть одни и те же задачи на одной доске. Этот выпуск программу не запускал.
