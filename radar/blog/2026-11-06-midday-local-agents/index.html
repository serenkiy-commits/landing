AnyModelBot: локальный бот на любой модели

Описание modelflare-ai/AnyModelBot: открытая, локально-ориентированная альтернатива Grok Bot, OpenAI dots и Claude Duet. Бот живёт на вашем компьютере или сервере, работает с разными моделями через один ключ Modelflare или через официальные API, отвечает в приложении, WeChat, Feishu, Telegram, Slack и Discord, помнит контекст, делает фоновые задачи, запускает команды и может управлять рабочим столом. По README приложение ставится на Windows, macOS и Linux, есть Docker; диалоги, память, файлы и ключи остаются на устройстве. Лицензия MIT, по API основной язык Python, 2722 звезды, push 5 ноября 2026.

Это десктопный агент, а не облачный сервис. Насколько удобны computer-use и каналы на вашей машине, в карточке не измерялось: это видно после установки из README и страницы релизов.

agent-purge: одна персона для нескольких coding-агентов

ZiChuanLan/agent-purge описан как локальный инструмент: одна персона и режимы подстановки system prompt для Codex, Claude Code, OpenCode, Grok, OMP, Hermes, pi, ZCode и других, с веб-консолью на 127.0.0.1:7788. В README есть режимы replace, strict, append и off, установка через npm, hot-switch у части хостов и явное предупреждение, что проект не раздаёт jailbreak-промпты. Нужен Node.js 20+. Лицензия MIT, JavaScript, 1317 звёзд, push 6 ноября 2026.

Полезно, если вы держите несколько CLI-агентов и хотите одну рабочую личность без ручного копирования файлов. Совместимость конкретной версии хоста смотрите в таблице README: там указаны проверенные номера и границы hot-switch.

whatsmyagentdoing: офис, где видно всех агентов

Описание Charonyuu/whatsmyagentdoing: навык для Claude Code и Codex — команда /myoffice открывает живой «офис», где видно, чем заняты сессии Claude Code, Codex, Gemini CLI, Copilot CLI, OMP, Kimi Code, DeepSeek Harness, Grok Build, OpenCode и Hermes. Данные читаются только с локальных JSONL и SQLite, сервер слушает 127.0.0.1, API-ключей не нужно. Есть 2D и 3D вид, статусы «думает / инструмент / ждёт вас», панель Today по токенам. Лицензия MIT, JavaScript, 382 звезды, push 5 ноября 2026.

Это обзорщик логов, а не оркестратор. Если формат логов у агента сменится, статусы могут деградировать — это прямо написано в разделе Limits README.

Claude-Cage: лёгкая Linux-VM под Claude

Lee-xeo/Claude-Cage описан как лёгкая Linux-виртуальная машина в десктоп-приложении: терминал, браузер и редактор в одном окне, отдельный сетевой прокси и настройки отпечатка (часовой пояс, язык) внутри Cage. В README заявлены macOS 14+ на Apple Silicon, Windows 10/11 x64 и Debian/Ubuntu x86_64; Windows и Linux помечены как ещё на приёмке. Встроенной подписки на прокси и аккаунтов Claude проект не даёт. Лицензия MIT, Go, 334 звезды, push 6 ноября 2026.

Версия в README на момент текста — 0.1.5-alpha.2. Это изоляция рабочей среды, а не гарантия от ограничений платформы: авторы прямо пишут, что сетевые проверки не заменяют аудит безопасности и не обещают сохранность аккаунта.
