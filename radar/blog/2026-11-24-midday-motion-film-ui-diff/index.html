ui-diff: визуальный diff интерфейса в pull request

imuratalpay/ui-diff в описании GitHub — скриншоты до и после, подсвеченный пиксельный diff и короткий UX-итог для изменений интерфейса в pull request, скилл агента. README уточняет: комментарий в PR один и липкий, а картинки остаются приватными. По умолчанию publish коммитит их в сиротскую ветку ui-diff-assets того же репозитория и не трогает рабочее дерево, индекс и остальные ветки. Ссылка вида https://github.com/<owner>/<repo>/raw/ui-diff-assets/…, по README, открывается у вошедшего пользователя с правом чтения. Для публичного репозитория publish отказывается, пока не передан --allow-public-repo; неизвестная видимость требует --assume-private. Это скилл для Claude Code, Cursor и Codex и CLI на TypeScript, который человек и CI запускают сами. Сайт — skills.muratalpay.me/ui-diff. Кому: тем, кто хочет увидеть, что правка сдвинула в интерфейсе, до того как комментарий уйдёт в PR. Проба из README: git и Node.js 20.10+; на Windows README просит WSL2. GitHub CLI (gh auth login) нужен для ui-diff publish и для --pr. Клон, затем install.sh --claude (Cursor читает тот же каталог скиллов; --codex ставит скилл для Codex), алиас на skills/ui-diff/bin/ui-diff.mjs, в своём проекте ui-diff init и ui-diff check. Первый запуск качает Chromium, README называет объём около 150 МБ. Результат лежит в .ui-diff/. Наружу ничего не уходит, пока не запущен publish. Что делает CLI, по README. Изменённые файлы интерфейса сопоставляются с маршрутами через ui-diff.config.json, соглашения Next.js, SvelteKit, Nuxt, Astro, Remix, TanStack Router и обычного HTML и через граф импортов. Смена UI-зависимости в package.json или lock-файле помечает каждый маршрут затронутым. База и голова поднимаются во временных git worktree, каждая на своём порту, либо берутся готовые preview URL. Снимки базы кэшируются в .ui-diff/cache/, пока коммит базы и настройки съёмки те же. Playwright снимает обе стороны одинаково: замороженные часы, посеянные Math.random и crypto, остановленные анимации и каретка, дождавшиеся веб-шрифты, маски, спрятанные полосы прокрутки. Кадр переснимается, пока два подряд не совпадут. По умолчанию видовые экраны — desktop и mobile. Diff считает pixelmatch. Для изменённой области README описывает пару «база | голова», мигающий GIF и кроп «до | после | diff». Карта элементов называет, что изменилось в стиле, например отступ ссылки. Комментарий один: его находят по скрытому маркеру и правят на месте. ui-diff check сравнивает рабочее дерево с базой слияния и ничего не публикует. Код выхода 0, если визуально ничего не изменилось, 1 если изменилось, 2 при ошибке. Пример в README — статическая страница двумя коммитами в самом репозитории; вердикт этого прогона README формулирует как «5 measured changes on 1 route». Публикацию README проверял на локальном bare remote и пишет, что настоящий PR при этом не вызывался. Этот выпуск пример не прогонял. Лицензия MIT.
