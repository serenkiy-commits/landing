agent-desktop: computer use через дерево доступности

Описание vercel-labs/agent-desktop: Computer use CLI for AI agents. По смыслу репозитория и топиков это CLI, через который агент управляет десктопом по дереву доступности, без опоры на скриншоты и пиксели. В топиках названы macOS, MCP, accessibility и desktop-automation. Лицензия Apache-2.0, язык Rust, 18186 звёзд, push 6 ноября 2026.

Смотреть тем, кто подключает агентам работу с настольными приложениями. Насколько стабильно ходит конкретный UI на вашей машине, в этой карточке не измерялось: это смотрят в README и на своём стенде.

worktrunk: git worktree под параллельных агентов

max-sixty/worktrunk описан как CLI для управления Git worktree, рассчитанный на параллельные сценарии ИИ-агентов. В топиках указаны agents, claude-code, codex, git и worktrees. Сайт проекта: worktrunk.dev. Лицензия dual MIT / Apache-2.0 (по файлу LICENSE), язык Rust, 11814 звёзд, push 6 ноября 2026.

Практический смысл — когда несколько агентов правят один репозиторий и мешают друг другу в одной рабочей копии. Карточка не обещает, что любой агент «сам» выберет ветку: это инструмент worktree, а не оркестратор модели.

auto-ontology: семантика и граф знаний для агентов

NVIDIA/auto-ontology описан как Python-фреймворк для семантических, графовых слоёв рассуждения над данными: детерминированная генерация запросов, контекст и объяснимость для LLM и агентных сценариев. Лицензия Apache-2.0, Python, 9152 звезды, push 6 ноября 2026.

Это инфраструктура под text-to-SQL и аналитику, где ответы должны опираться на зафиксированные определения, а не на угадывание метрик. Скорость и точность на ваших данных в выпуске не проверялись.

skills: медиа и 3D из coding-агента

scenario-labs/skills описан как skills и MCP для картинок, видео, аудио и 3D: выбор модели, цена до траты, консистентность персонажей и бренда, плюс контуры под Blender, Maya, ZBrush, Unreal и Unity. В топиках есть claude-code, codex, mcp и agent-skills. Лицензия MIT, Python, 3415 звёзд, push 7 ноября 2026.

Подходит тем, кто гоняет продакшн-медиа через coding-агентов. Качество картинки и стоимость прогона зависят от выбранных моделей и ключей — в карточке этого нет.
