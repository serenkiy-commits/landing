player: 2.5D-персонаж в браузере

livliv-dev/player в описании — лёгкий 2.5D-проигрыватель персонажа для веба с липсинком и трекингом лица по вебкамере. По README это WebGL2 без зависимостей, ядро около 30 KB в gzip. Липсинк с микрофона, аудио или видео и трекинг лица по вебкамере через MediaPipe работают в браузере и грузятся по требованию. Один API проигрывает персонажей LivLiv, VRM и PNGTuber. В каталоге characters/ 21 готовый персонаж. Демо: livliv-dev.github.io/player. Лицензия Apache-2.0, язык TypeScript, 1388 звёзд, push 9 ноября 2026 в 06:08 UTC. На момент запроса репозиторий не был архивным.
