magpie: одна модель на все агенты

По описанию yetone/magpie даёт выбрать модель для разных агентов из меню в панели: Codex на DeepSeek, Claude Code на Kimi. В README добавлены Gemini CLI на GLM и OpenCode на подписке ChatGPT. Один локальный шлюз обслуживает все агенты, а когда лимит аккаунта кончается, он переходит к следующему. Лицензия MIT, язык Go, 29026 звёзд.

Полезно тем, кто держит несколько агентов и несколько ключей и устал переписывать настройки руками. Как шлюз ведёт себя под нагрузкой и что происходит с вашими ключами, в README не измерено: это надо проверять у себя.

Jev Ultrafast: веб-агент с таблицей элементов

browser-use/jev-ultrafast описан как самый быстрый и дешёвый веб-агент. Это оценка авторов. По README на каждом шаге страница превращается в таблицу элементов, а агент выбирает одну из операций: клик, ввод текста, выбор, прокрутка, ожидание. Маленькая модель пишет текст только когда операция — ввод. Лицензия MIT, Python, 24134 звезды.

В README приведён пример: поиск билетов Цюрих — Лондон на Google Flights за 7,1 секунды. Это цифра авторов на одном сценарии, на других сайтах результат будет другим.

elephant-goldfish-model: проектирование и проверка до кода

google/elephant-goldfish-model — плагин с навыками для проектирования и ревью ПО с ИИ-агентами. Схема такая: «слон» держит контекст проекта и пишет спецификацию, «золотая рыбка» проверяет её с чистым контекстом, без прежнего разговора, а решения принимает человек. В README есть установка для Claude Code, Codex и Antigravity. Лицензия Apache-2.0, Python, 11189 звёзд.

Подходит для фичи, где сначала нужны решения, а потом код. Для мелкой понятной правки сами авторы советуют обычный рабочий процесс.

ZCode: рабочее место для кодинга от Z.ai

zai-org/ZCode описан как harness кодового агента от Z.ai. По README это ИИ-рабочее место в трёх видах: десктопное приложение, браузерный интерфейс и терминальный агент. В репозитории лежат клиент, серверная часть, общий интерфейс и исходники CLI агента. В списке обновлений на 3 ноября 2026 указана версия v3.17.2. Лицензия Apache-2.0, TypeScript, 8451 звезда.

README в основном на китайском, есть английская версия. Для сборки нужны Git, Node.js и pnpm нужных версий из файла mise.toml.

Что из этого следует

Все четыре проекта работают вокруг агента, но с разных сторон: выбор модели, браузер, проектирование и своё рабочее место. Общее проверяемое одно: открытый код, названная лицензия и push 3 ноября 2026. Число звёзд показывает интерес на дату замера, не качество кода и не безопасность зависимости.

Перед внедрением перечитайте лицензию на странице репозитория. Среди этих четырёх нет AGPL: два проекта под MIT и два под Apache-2.0.
