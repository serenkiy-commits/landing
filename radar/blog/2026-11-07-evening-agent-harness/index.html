SPACE: песочницы на Firecracker для агентного кода

perplexityai/SPACE — Sandboxed Platform for Agentic Code Execution от Perplexity. Это платформа песочниц на микро-ВМ Firecracker: приложение через HTTP API создаёт Linux-окружение по шаблону, запускает команды, читает вывод и управляет жизненным циклом (pause, suspend, удаление). Вывод команды идёт по отдельному data-plane с токеном сессии. В документации есть развёртывание в Kind, архитектура без Kubernetes, operator CLI и обёртка совместимости с E2B Python SDK. Лицензия Apache-2.0, основной язык Rust, 2076 звёзд, push 7 ноября 2026. Документация: space.docs.perplexity.ai.

Смотреть тем, кто строит свой сервис с агентами и нуждается в изолированном выполнении чужого кода, а не в локальной политике на одном хосте.

TokenEconomizer: контроль стоимости без смены агента

microsoft/TokenEconomizer — открытый проект Microsoft Research и UC Berkeley: black-box контроль стоимости coding-агентов по опыту прошлых сессий в том же репозитории. Три механизма в README: micro-skills (запоминают, как устроен репозиторий), pruning инструментов (убирают то, чем в этом репо не пользуются) и вмешательство при зацикливании на одной ошибке. Работает с Claude Code, Codex, GitHub Copilot CLI и Pi без замены самого агента. Авторы публикуют измерения на задачах SWE-Bench и ссылку на arXiv; в этом выпуске цифры с их стенда не перепроверялись. Лицензия Apache-2.0, Python, 4941 звезда, push 6 ноября 2026. Страница проекта: tokeneconomizer.github.io.

Полезно, если агент часто ходит в одни и те же репозитории и счёт за токены растёт из‑за повторов и лишних инструментов.

LearnHarness: обвязка агента для обучения

amosblomqvist/learnharness — десктопная обвязка, в которой агент измеряет текущее понимание, строит карту зависимостей до цели, учит по шагам и даёт практику. Знания копятся в графе утверждений и цепочек рассуждений между сессиями; можно прикладывать файлы с диска. Есть сборки для macOS (Apple Silicon) и Windows. Лицензия AGPL-3.0, TypeScript, 6104 звезды, push 7 ноября 2026. Сайт: learnharness.ai.

Это не coding-агент для репозитория, а учебный контур вокруг агента. AGPL-3.0 стоит учесть, если планируете встраивать код в свой продукт.

OpenQodex: отдельное ревью правок агента до push

openqodex/openqodex — открытый AI code review для coding-агентов. Отдельный ревьюер проверяет незапушенные коммиты и незакоммиченные правки: сначала сканеры без модели (в том числе gitleaks, semgrep, osv.dev по lockfile), затем finder- и verifier-сессии на Claude Code или Codex с проверкой цитат скриптами. По умолчанию агент, который написал код, его не ревьюит. Ставится через npx openqodex init, свой аккаунт сервиса не нужен. Поддерживаются Claude Code, Codex, Cursor и Cline. Лицензия Apache-2.0, TypeScript, 1075 звёзд, push 7 ноября 2026. Сайт: openqodex.com.

Подходит как локальный gate перед push, когда агент пишет много диффов и нужен второй проход без отдельного SaaS-ключа.

Что из этого следует

SPACE отвечает на вопрос «где безопасно выполнять код агента». TokenEconomizer — «как дешевле гонять того же агента в знакомом репо». LearnHarness показывает обвязку агента вне кода: обучение человека. OpenQodex закрывает проверку результата до push. Число звёзд — интерес на 7 ноября 2026, не оценка качества и не аудит безопасности.

Лицензии: Apache-2.0 у SPACE, TokenEconomizer и OpenQodex; AGPL-3.0 у LearnHarness. У SPACE для продакшна нужен свой хостинг песочниц; у OpenQodex ревьюер опирается на уже установленный Claude Code или Codex.
