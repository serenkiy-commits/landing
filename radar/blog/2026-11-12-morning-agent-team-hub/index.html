yogurt: заметки встречи без бота в созвоне

FrigadeHQ/yogurt в описании GitHub — приватные заметки встреч с ИИ, бесплатно и с открытым кодом. Сайт — yogurt.so. README пишет, что Yogurt записывает созвон и не добавляет бота во встречу. Справка docs/README.md уточняет состав: программа пишет микрофон и звук звонка, расшифровывает встречу и кладёт Summary рядом с вашими заметками. Обработка остаётся на компьютере. В разделе Privacy той же справки: встречи не загружаются, телеметрии нет. В сеть программа выходит, чтобы скачать модели с Hugging Face, на Mac — за опциональными речевыми ассетами Apple, и чтобы проверить обновления на GitHub. Сборки в README: Mac (Apple Silicon), Windows x64 и Linux x64 AppImage. В справке порог — 8 ГБ памяти. Mac — macOS 14.4 или новее, Windows — 10 версии 2004 или новее, Linux — Ubuntu 22.04 или совместимая система новее, с PulseAudio или PipeWire.

Установщик Windows в справке помечен как ещё не подписанный: система может остановить первый запуск. Календарь и имена говорящих из приложений звонка в справке указаны только для Mac. Запись начинается после клика. В Settings → AI apps можно включить локальный MCP: другое ИИ-приложение читает встречи, заметки и расшифровки и не может их менять. Доступ выключен по умолчанию. Подключённое приложение, по справке, может отправить прочитанное в свою онлайн-модель. Данные лежат локально: на Mac в ~/Library/Application Support/Yogurt, на Windows в %APPDATA%\Yogurt, на Linux в ~/.config/Yogurt. README относит проект к Frigade, лицензия MIT.

Плюс неподписанный установщик Windows и то, что MCP по умолчанию выключен, а включённый отдаёт текст уже другому приложению. agentes-chat: команда и агенты в одном чате

agentes-chat/agentes-chat в описании GitHub — self-hosted альтернатива Slack. Команда и ИИ-агенты работают в каналах и личных сообщениях. Агенты на Claude, ChatGPT/Codex, Gemini или Grok, с MCP-инструментами, своим компьютером и браузером, рутинами, памятью и подтверждениями. Клиенты — web, desktop и phone. Поставка — Docker Compose и Postgres. Сайт — agentes.chat. README добавляет, что тот же код можно поднять у себя или открыть в agentes.chat Cloud. На своём Linux-сервере установка в README — одна команда curl. Скрипт ставит недостающее, Docker спрашивает перед установкой, и выводит сервис в сеть Tailscale, приватно и с HTTPS. Подробности, телефон, свой домен, обновления, бэкапы и запуск без Docker — в SELF_HOSTING.md. Ключ модели организация добавляет в приложении. В списке README помимо Claude, OpenAI, Gemini и Grok есть DeepSeek, Kimi, Z.ai, MiniMax и OpenRouter.

Агенты в README — участники пространства, не бот в боковой панели. У каждого роль, инструкции, модель, месячный бюджет, который проверяется перед вызовом, и владелец, которому приходят подтверждения и предупреждения о бюджете. Слияние, выкладка, откат и то, что коннектор помечает как чувствительное, ждут владельца агента или администратора: карточка в чате, действие выполняется один раз и в том виде, в котором его подтвердили. Организация подключает MCP-сервер один раз, агент получает только выданные ему области. Браузер агента, почтовые ящики, коннектор Postgres, телефон и десктоп в таблице README помечены как Beta. Сборку Mac README называет не нотаризованной, установщик Windows — неподписанным. Codex через подключённый компьютер README помечает как всё ещё в тестировании.

myco: CLI-агенты на разных машинах через один хаб

chenhg5/myco в описании GitHub связывает Claude Code, Codex и любой CLI-агент между машинами. Агенты находят друг друга, делегируют задачи и отвечают через один хаб. Поставка — один бинарник на Go, установка в одну строку. README называет три сценария одного хаба. Облачный агент из той же беседы выполняет команду на вашем компьютере или передаёт задачу уже настроенным там Claude Code или Codex и получает ответ. Ваш агент отдаёт задачу агенту коллеги вместе с нужным контекстом. Свои агенты видят друг друга и обмениваются результатами. Компьютер, по README, не открывает порты. Команда выполняется с уже выданными ему правами, только для агентов из списка разрешённых, и каждая команда записывается. Приложение: macOS (один DMG на Apple Silicon и Intel; README пишет, что сборка подписана и нотаризована Apple), Windows как preview и пока без подписи кода, Linux и серверы — командная строка. Хаб можно запустить на этом компьютере или поставить на свой сервер одной строкой из README.

У shell-узла в README есть границы. Он выполняет одну команду за раз, каждую в своём процессе: нет интерактивного терминала, cd не переносится на следующую команду. Таймаут по умолчанию — 60 с, потолок вывода — 64 КБ. Файлы читают и пишут командами. Передачи файлов, экрана и мыши нет. В командном хабе у агента есть список, кому можно писать. Получатель видит, кто спрашивает, и что запрос пришёл от коллеги, а не от владельца: он остаётся в пределах, которые разрешил владелец. Для командного хаба README описывает опциональное сквозное шифрование: сообщение читают две стороны и их владельцы, не хаб, его администраторы и остальные участники. Задача продолжается в собственной сессии агента. В списке README — Claude Code, Codex, облачные сессии claude.ai, Pi, Kiro и Gemini CLI. Обзор агентов — myco agent list, задача с ожиданием ответа — myco message send --wait.

Кому: тем, у кого Claude Code, Codex и другие CLI-агенты уже запущены на разных машинах и нужен один хаб, чтобы они находили друг друга и делегировали задачи. Вариант MACaQ-R, по README, уточняет коды весов в уже квантованном GGUF и сохраняет его формат и блочные шкалы: такой файл запускается обычной установкой llama.cpp, командами llama cli и llama serve.
