nitromta: почтовый движок Nitrosend

nitrosend/nitromta — открытый движок доставки почты Nitrosend, написанный на Rust. Он совместим с SES v2 API: SendEmail, SendBulkEmail, шаблоны, identities, configuration sets, suppression list и события в стиле SES через подмножество SNS. Совместимость проверена официальными SDK: код отправки можно оставить и сменить endpoint, чтобы письма уходили со своих IP. Письмо подтверждается только после записи на диск и переживает падение процесса.

У того же движка есть управляемая версия Nitrosend — коммерческий вариант. Кому: тем, кто шлёт транзакционную и массовую почту и хочет уйти с SES на свои сервера. Язык Rust, лицензия Apache-2.0, 126 звёзд на 16.11.2026, 06:20 МСК, последний push 11.11.2026.

HomeRoll: «Фото» для своего Immich

silentprovider423/HomeRoll — независимый iPhone-клиент для self-hosted Immich. По виду и поведению он повторяет приложение «Фото» iOS 26: сетка с зумом на 1, 3 и 5 колонок, месяцы и годы, просмотр, редактор, воспоминания, поиск, люди, альбомы и поездки. Автор пишет, что пользуется приложением ежедневно с Immich v3.3.5. Это личный проект без гарантий поддержки, интерфейс на английском и немецком.

Есть сестринское приложение для macOS — HomeRoll Desktop. Проект не связан с Apple и с Immich/FUTO. Язык Swift, лицензия GPL-3.0, 159 звёзд на 16.11.2026, 06:20 МСК, последний push 15.11.2026.

DeskVoice: телефонная станция на своей VPS

DeskLabs-OpenSource/DeskVoice ставится на свою VPS. Агент отвечает на звонок, вызывает инструменты во время разговора, просит одобрения у человека, когда это нужно, переводит звонок и продолжает задачи после окончания вызова. README на португальском, есть английская и испанская версии.

По словам авторов, установка, обновление из интерфейса, бэкап и восстановление, а также откат неудачного обновления проверены на реальной VPS. Реальные звонки делались через OpenAI Realtime. README разделяет доказанное, экспериментальное и планы. Язык TypeScript, лицензия MIT, 120 звёзд на 16.11.2026, 06:20 МСК, последний push 16.11.2026.

chiban-oss: земельные дела небольшого города

chiban-org/chiban-oss собирает работу вокруг земельного участка: разрешения на строительство, инспекции, заявки Planning Board и ZBA, контроль нарушений. Сроки и формулировки уведомлений берутся из «пакета штата», у каждого срока видна норма закона. Формы, сборы и шаблоны настраивают сотрудники без кода. Все записи можно выгрузить в открытые форматы: текст, таблицы, Excel и PDF/A. Софт можно разместить на своём сервере.

Для РФ это скорее пример хорошо продуманного продукта для госуслуг и муниципалитета, чем готовый инструмент. Язык TypeScript, лицензия AGPL-3.0, 126 звёзд на 16.11.2026, 06:20 МСК, последний push 12.11.2026.
