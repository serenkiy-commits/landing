HolyArrs: одна медиатека вместо шести приложений

HolyArrs/HolyArrs в описании GitHub — одно self-hosted приложение для сериалов, фильмов и музыки. README ставит его на место связки Sonarr, Radarr, Lidarr, Bazarr, Prowlarr и Seerr: один вход и один порт. Сайт — holyarrs.com, справка — docs.HolyArrs.com. Запуск в README — Docker Compose с образом holyarrs/holyarrs:latest и портом 6262. Образы README относит к amd64, arm64 и armv7. Тег 1.1.4 README описывает как одну точную версию, которая не двигается. Заметка в шапке README называет текущие правки HolyArrs 1.1.4.

По README человек просит название, HolyArrs ищет его в Sources, выбирает релиз правилами Pick, отдаёт уже стоящему загрузчику и раскладывает файл в библиотеку. Список загрузчиков в README: qBittorrent, Transmission, Deluge, rTorrent, aria2, SABnzbd, NZBGet. Медиасерверы: Plex, Jellyfin, Emby. Источники: индексер Torznab или Newznab, либо Prowlarr или Jackett. Отдельно README пишет, что само HolyArrs файлы не качает и загрузчик не заменяет. Постеры и описание README берёт с сервера метаданных HolyArrs, свои ключи тоже подходят. Импорт читает настройки Sonarr, Radarr, Lidarr, Prowlarr, Bazarr, Seerr, Overseerr, qBittorrent и SABnzbd и, по README, эти приложения не меняет. В шапке README указаны около 16.1 MB на скачивание и около 95 MiB RAM в простое на чистой установке. В таблице сравнения простой записан как ~140 MiB, сноска относит замер к 2026-11-08 на 10 000 названий, а сжатый размер образа — к 2026-11-13 и версии 1.1.3. Этот выпуск оба числа не перепроверял.

dalibre: библиотека calibre одним окном

Интерфейс — нативный UI MyGo, без webview и без cgo, один бинарник. Поле homepage в ответе API — dalibre.randynamic.org. Макет в README ведёт на файл Figma. Сборка релиза в README — go tool mygo build ./cmd/dalibre, результат README кладёт в cmd/dalibre/build. Обновления приложение берёт из релизов этого репозитория. Совместимость README описывает так: новые библиотеки используют схему metadata.db calibre с user_version 28, Dalibre регистрирует SQL-функции триггеров calibre, папки книг следуют именованию calibre, правки пишут metadata.opf. Удалённые книги README отправляет в корзину системы. Встроенные источники: Project Gutenberg, поиск метаданных Google Books и NeoDB. Чужой источник — плагин из plugin.json и JavaScript в песочнице.
