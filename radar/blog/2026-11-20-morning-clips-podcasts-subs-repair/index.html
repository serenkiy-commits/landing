NeonClipping: вертикальные клипы на своей машине

iamajmeena/neonclipping в описании GitHub — вставил ссылку и получил вертикальные клипы 9:16 с субтитрами примерно за две минуты. Это бесплатный локальный движок с открытым кодом: сначала звук, субтитры YouTube, локальная языковая модель. README собирает длинные ролики YouTube, Twitch и Kick или свой файл MP4 в вертикальные клипы с заголовком и хуком. Счёт, подписка и отправка ролика наружу README не требует: работа идёт на своей машине. Быстрый режим, он же режим по умолчанию для роликов длиннее 10 минут, качает только звук, берёт субтитры YouTube с таймингом слов, а если их нет — локальную модель речи. Кандидатов дают скачок громкости, повышенный голос и переход от тишины к громкости. Локальная модель через Ollama читает текст отрывка, ставит оценку, пишет заголовок и хук и прищёлкивает начало и конец к границам фраз. Скачивается выбранный кусок, не весь файл. Глубокий режим качает ролик целиком и добавляет движение по оптическому потоку. README публикует замеры быстрого режима на одной машине и пишет, что время зависит от сети и процессора. Этот выпуск те прогоны не повторял. Сервер README привязывает только к 127.0.0.1.

Кому: тем, кто режет длинные стримы и ролики в вертикальные клипы с субтитрами и хочет оставить файл на своей машине. Как попробовать по README: на Windows скачать NeonClipping-Setup.bat с сайта iamajmeena.github.io/neonclipping или со страницы релизов и запустить его. Скрипт проверяет компьютер, ставит Python и FFmpeg, если их нет, и открывает программу. Для Mac и Linux README даёт install.sh и прямо пишет, что на настоящем Mac скрипт ещё не проверяли. Ручной путь: Python 3.10 или новее, FFmpeg в PATH, клон репозитория, ./run.ps1 на Windows или ./run.sh на Linux и macOS, затем http://127.0.0.1:8770, ссылка и кнопка Make clips. Ollama с моделью llama3.2:3b README называет необязательной: без неё клипы выбирает оценка звука и движения. Отдельной домашней страницы в снимке API нет, адрес установки стоит в README. SubCast: подкасты и YouTube с двумя языками субтитров

joeseesun/subcast в описании GitHub — настольное приложение: двуязычные субтитры, подробный разбор и вопросы к модели для зарубежных подкастов и YouTube. README собирает его для macOS, Windows и Linux. Подписка принимает канал YouTube, Apple Podcasts, Сяоюйчжоу или любой RSS, есть поиск подкаста по имени. Отдельное видео или выпуск можно открыть сразу. Официальные субтитры README берёт первыми. Если их нет, звук распознаёт модель на устройстве: по умолчанию Qwen3-ASR 0.6B, около 1 ГБ, звук с компьютера не уходит. Можно выбрать облачное распознавание. Перевод по умолчанию — бесплатный Google, его можно сменить на свою модель. На экране три режима: оба языка, перевод или оригинал. Выпуск, который уже распознал кто-то другой, открывается с готовыми субтитрами: README пишет, что уходит только текст, без звука, и отправку можно выключить в настройках. Разбор и ответы идут через свою модель. README перечисляет DeepSeek, SiliconFlow, Kimi, Claude, OpenAI, OpenRouter, Gemini, Ollama, LM Studio и любой интерфейс, совместимый с OpenAI. Ключ хранится в системной связке ключей. В ответе есть метки времени, по ним README возвращает к фразе. У отобранных передач README описывает отдельный длинный разбор выпуска на китайском.

Кому: тем, кто слушает длинные зарубежные подкасты и ролики YouTube и хочет субтитры на двух языках, разбор и вопросы по тексту выпуска на своём компьютере. Как попробовать по README: скачать сборку с subcast.qiaomu.ai или из релизов GitHub. Для macOS — отдельные dmg под Apple Silicon и Intel, README называет их подписанными и нотаризованными. Для Windows 10/11 — установщик; README пишет, что подписи кода ещё нет и SmartScreen при первом запуске спрашивает подтверждение. Для Linux — AppImage, deb и rpm. Новая версия качается в фоне и встаёт после перезапуска. Сборка из исходников: Node.js 22 или новее, стабильный Rust и CMake, затем npm install и npm run tauri dev. Стек README — Tauri 2 на Rust и React/TypeScript. Лицензия AGPL-3.0: пользоваться, менять и распространять можно; если раздаёте изменённую версию или поднимаете её как сетевой сервис, README требует открыть полный исходный код под той же лицензией. Облачное распознавание, перевод и ответы отправляют текст выбранному сервису. Для YouTube из материкового Китая README просит прокси. Домашняя страница в снимке API — subcast.qiaomu.ai. Subnook: подписки на Android

capllen/Subnook в описании GitHub — локальное приложение Android для подписок. Даты счетов сдвигаются сами, до срока приходит ежедневное напоминание, в описании — курсы более чем 30 валют, календарь счетов, статистика трат, виджет на домашнем экране и более 240 готовых сервисов. README ведёт подписки, регулярные счета и рассрочки. Запись хранит название, сумму, валюту, период, дату следующей оплаты, способ оплаты, категорию и заметку. С автопродлением день счёта сам пишет расход и сдвигает дату. Без автопродления дата меняется после отметки «я оплатил». Напоминание README ставит каждый день, по умолчанию начиная за 3 дня; срок можно задать от 0 до 30 дней. Просроченная ручная оплата напоминается ежедневно, в уведомлении есть кнопка «оплачено». Календарь показывает иконки списаний на день. Главная считает средний расход за неделю, месяц и год. Виджет показывает месячный расход и ближайшие списания. Данные README хранит на устройстве. Копия — файл JSON или свой WebDAV; в сеть для выгрузки приложение выходит только если WebDAV задан, логин и пароль остаются на устройстве. README называет 31 распространённую валюту: курс с open.er-api.com обновляется каждые 24 часа. Готовых сервисов README пишет 250+.

Кому: тем, кто держит подписки и рассрочки на телефоне Android и хочет даты, напоминания и сумму на устройстве. Как попробовать по README: APK из релизов GitHub, Android 8.0 или новее. Сборка: Kotlin, Jetpack Compose, JDK 17 или новее, Android SDK с compileSdk 36. В Android Studio открывают каталог Subnook/. Из этого каталога команда ./gradlew assembleDebug. Файл лицензии README относит к PolyForm Noncommercial 1.0.0: личное использование, учёба и исследование можно, коммерческое README запрещает, пока автор не разрешит через issue. DEADBOARD: ремонт плат в браузере

tholtman1-del/deadboard в описании GitHub — тренажёр ремонта плат: диагностика и ремонт смоделированных плат на стенде, в браузере. README ставит сломанную плату на стенд и даёт инструменты техника. Схема считается симулятором в духе SPICE: прибор показывает то, что делает схема, а не заготовленный ответ. В списке приборов README: мультиметр (напряжение, сопротивление, диод, ёмкость, ток в разрыв), лабораторный источник с ограничением тока, осциллограф, тепловизор, охлаждающий спрей, изопропиловый спирт и канифоль. Пайка, термофен, оплётка, резак дорожки, перемычка и установка новой детали тоже есть. README пишет, что шов может быть холодным, площадка может оторваться, а капля не на месте замкнёт шину. Кроме учебных плат README импортирует проекты KiCad. Два открытых образца идут в комплекте: материнская плата ноутбука MNT Reform 2 (README пишет 530 деталей) и базовая плата Antmicro Jetson (392 детали). У сценария есть цели на стенде. Свои неисправности README предлагает задавать во вкладке автора: замыкание, обрыв, утечка, уход номинала, плавающий дефект. Где значение оценено или форма сигнала синтезирована, приложение, по README, говорит об этом. Языки интерфейса — английский и русский.

Кому: тем, кто учится искать неисправность на плате и хочет стенд в браузере, без паяльника и живой платы. Как попробовать по README: открыть deadboard.org. Локально нужны Node.js 20 или новее и браузер: npm install, npm run dev, адрес http://localhost:5173. Стенд рисует через WebGPU, если браузер его даёт, иначе через WebGL2. Выбор рендера — ?renderer=webgl2 или ?renderer=webgpu в адресе. Проверка из README: npm test. Лицензия проекта — Apache-2.0. Демоплаты в public/demos/ README оставляет под лицензиями исходных проектов, CERN-OHL-S-2.0 и Apache-2.0. Имена MNT Reform и Jetson README помечает как товарные знаки, без заявления о поддержке производителем. Домашняя страница в снимке API — deadboard.org.
