chimera-vocal-synth: синтез из модели дыхательных путей

jamesondh/chimera-vocal-synth в описании на GitHub — the ultimate vocal synthesizer: sing, speak, beatbox. По README это голосовой синтезатор на физическом моделировании в браузере: звук получается из симуляции дыхательных путей (лёгкие, связки или сиринкс, разветвлённый вокальный тракт, губы, нос), без сэмплов. Движок на Rust собирается в WebAssembly и работает в AudioWorklet. Тот же код запускается нативно для тестов и CLI chimera. Режимы в README: Play (двигать язык, губы и челюсть в разрезе головы, Web MIDI), Speak (английский текст через CMUdict или IPA), Sing (piano roll с лирикой), Beatbox (пэды и секвенсор), Bestiary (певчая птица, тюлень, аллигатор, слон).
