WinRust: оболочка Windows на Rust

Lemxy/WinRust в описании GitHub — замена оболочки Windows на Rust: панель задач, файловый менеджер, поиск по NTFS, диспетчер задач, очистка диска, один установщик exe. README называет это набором небольших нативных программ без .NET и без Electron. В таблице плагинов: rust-search (поиск по всем дискам NTFS, Alt+Space; при установке выключает службу Windows Search), rtaskmgr-win32 (диспетчер задач на Ctrl+Shift+Esc и очистка диска rs-du), topbar (нижняя панель в духе Windows 11 и горячие клавиши reshell), rust-explorer (файловый менеджер с вкладками; проводник перестаёт быть оболочкой; нужен topbar; на чистой установке выключен), wiztree (карта диска), photoview, rust-settings (экран, звук, питание, сеть, Bluetooth, обновления). Отдельно и только из командной строки: debloat (телеметрия, Copilot, Recall, реклама в меню «Пуск»; значения сохраняются и возвращаются при удалении) и purge (удаление встроенных приложений в духе Tiny11; README пишет, что отмены нет). Плагин chrome-rs README помечает как ещё не устанавливаемый. Кнопка в установщике или пункт меню переключает программы WinRust на русский. Стили панели README перечисляет шесть: Normal, Terminal, Floating dock, Tiling, White road, Ruby.

Кому: тому, кто хочет заменить панель, проводник, поиск и диспетчер задач Windows своими программами на Rust и поставить их одним exe. Как попробовать по README: скачать WinRust.exe из последнего релиза, Windows 10/11 x64, запустить от имени администратора, отметить компоненты и нажать установку. Перед установкой README создаёт точку восстановления и просит сначала проверить на запасной машине или в виртуальной машине: поиск Windows выключается, штатная панель прячется, оболочкой может стать не Explorer. Файл README называет неподписанным, SmartScreen предупредит. Снятие всего — кнопка Remove all в том же окне; если панели и рабочего стола нет, README даёт путь Ctrl+Alt+Del → диспетчер задач → explorer.exe, затем Remove all. agy-fast: плагин MCP для Antigravity

INK-Q/agy-fast в описании GitHub — неинвазивный плагин-ускоритель MCP для Google Antigravity (CLI, Desktop и IDE). По заявлению автора он сокращает ходы LLM на 34%, квоту токенов на 31% и исходящий трафик на 40% и не трогает родной интерфейс и diff. README уточняет те же три ряда своей таблицы на основных сессиях: −33,7% ходов LLM на 10 действий, −31,5% расчётной квоты и −39,7% байт, которые инструменты отдают наверх. Рядом в той же таблице другие дельты, в том числе для длинного контекста и субагентов. База сравнения, по README, — 10 дней транскриптов: 14 основных сессий без плагина (5 771 ход) и 7 с плагином (901 ход). Это цифры автора, выпуск их не пересчитывал. Плагин README описывает как локальный сервер MCP по stdio с четырьмя составными инструментами: batch_search (до 20 поисков за вызов, rg или запасной путь на Node.js), apply_edits (несколько правок сразу, при ошибке файлы не меняются, если не включён bestEffort), read_slices (контуры символов и диапазоны строк), run_checks (сборка, типы, линтер, тесты). Хук SessionStart один раз подмешивает снимок репозитория, по README до 1,5 КБ. README пишет, что плагин не меняет окно diff, список изменённых файлов, контрольные точки, встроенные инструменты и проверки безопасности и не ставит хуки на каждый шаг.

Кому: тому, кто уже работает в Google Antigravity и хочет склеивать несколько поисков, правок и проверок в один вызов локального MCP. Как попробовать по README: нужен Node.js 20 или новее, npm install для запуска не требуется, пакеты dist/*.mjs лежат в репозитории. ripgrep необязателен. На macOS и Linux — curl -fsSL https://raw.githubusercontent.com/INK-Q/agy-fast/main/install.sh | sh. В PowerShell — irm https://raw.githubusercontent.com/INK-Q/agy-fast/main/install.ps1 | iex. Либо клон в ~/.gemini/config/plugins/agy-fast, либо agy plugin install и agy plugin enable agy-fast. В Desktop и IDE README просит включить плагин в Customizations → Installed и начать новую сессию. Проверка — install.sh doctor или node scripts/install.mjs doctor. Свой замер README предлагает офлайн: node dist/benchmark.mjs analyze --local. Фон проверяет обновление раз в 12 часов и не перезаписывает грязный git и установку через symlink. Лицензия в снимке API и в README — MIT. Домашняя страница в снимке не задана. PhoneDesk: телефон как панель для компьютера

howznguyen/phonedesk в описании GitHub — старый телефон как панель в духе Stream Deck и дашборд для Mac или Windows, без приложения, аккаунта и облака. README уточняет устройство: небольшой агент на компьютере отдаёт сенсорную страницу любому браузеру в той же сети Wi-Fi. На телефон ничего не ставится. Статус в README — ранний, 0.x: основная цель macOS, Windows экспериментальный, сборки без Developer ID и без нотаризации. Сетка плиток собирается на http://localhost:7420/manage/. README перечисляет плитки: приложения и их значки, адреса, сочетания клавиш, ввод текста, команды оболочки, макросы, громкость и медиа, графики CPU, памяти, сети и нагрузки, квоты Claude, Codex и Antigravity, локальные сессии Claude Code и Codex, ответ Allow / Deny и вопросы Claude Code с телефона (хуки по желанию), «сейчас играет», часы, погода, саундборд, уведомления, устройства Home Assistant, вебхуки. Раскладку может собрать MCP-сервер того же агента. Погоду README берёт у Open-Meteo (CC BY 4.0) и отсылает к PRIVACY.md за списком исходящих соединений. Описание про «без облака» в снимке API относится к отсутствию аккаунта и облачного сервиса самой панели.

Кому: тому, у кого есть Mac или ПК с Windows и старый телефон или планшет в той же сети Wi-Fi и кому нужна панель кнопок без отдельного приложения. Как попробовать по README. Mac, macOS 13 или новее: в Terminal curl -fsSL https://raw.githubusercontent.com/howznguyen/phonedesk/main/setup.sh | bash. Windows 10/11, README помечает путь как экспериментальный: в PowerShell без прав администратора irm https://raw.githubusercontent.com/howznguyen/phonedesk/main/setup.ps1 | iex. Установщик печатает QR, адрес вида http://your-mac.local:7420 и шестизначный PIN. Камера телефона открывает ссылку, PIN вводится один раз. На весь экран страницу добавляют на домашний экран. Первое сочетание клавиш на Mac просит доступ Accessibility. На Windows README предупреждает: клавиши, которые печатают текст, могут давать не те символы; запуск приложений, сочетания, медиа и громкость README относит к рабочим. Сборка из исходников — Bun 1.3+, bun install и bun run build. Linux README ещё не проверял. Агент слушает локальную сеть, страница управления отвечает только на localhost. Команды оболочки на плитках выполняет то, что человек сам туда записал. Лицензия MIT. Домашняя страница в снимке API — якорь README на GitHub. ORB: звук из подписи

stdevMac/orb-audio в описании GitHub — звук как код: движок подписи в звук с нуля на 15 млн параметров для агентов. Цепочка в описании: подпись, JSON Spec, DSP на 48 кГц. README раскладывает размер иначе, это тоже цифры автора: открытый планировщик — 5,1 млн параметров (в таблице результатов README — 5,10 млн, около 20 МБ), дальше JSON Spec и рендер на NumPy, 48 кГц, стерео. Необязательная модель детализации — 9,1 млн (в таблице — 9,06 млн). Вместе README пишет 14,16 млн. Модель детализации в репозиторий не входит: README даёт ей лицензию CC BY-NC-4.0 и пишет, что она обучена на ESC-50. Код и веса планировщика — Apache-2.0. Звук README описывает как функцию партитуры, не как файл-сэмпл: событие двигают числом, тот же Spec даёт тот же WAV. В Spec README называет 47 ролей, 13 текстур, 10 настроений, до 8 событий и длительность 2–30 с. Путь DSP README ограничивает NumPy: без torch, без весов и без GPU. Планировщик для свободного текста и грамматики подписи torch использует. README прямо пишет, чего движок не делает: не заменяет библиотеку записей, не открытый словарь text-to-audio (только свои роли и текстуры), не генератор музыки, не реальное время, без голоса и без голосовых животных.

Кому: тому, кто хочет отдать агенту звук как проверяемый JSON, а не как готовый WAV, и рендерить короткие cues на 48 кГц. Как попробовать по README. Клон, Python 3.11 или новее, pip install -e ".[dev]", затем python examples/04_no_torch.py — только NumPy, без весов. Полный конвейер с подписью: pip install -e ".[train]" и python examples/01_generate.py. Веса планировщика README ищет в weights/planner.pt (Git LFS), в переменной ORB_PLANNER или качает marcosmaceo/orb-planner с Hugging Face, если стоит huggingface_hub. Из оболочки — orb-generate с текстом подписи и --out. Локальная страница: python web/server.py --port 8765, адрес http://127.0.0.1:8765. Для агента: pip install "orb-audio[mcp,train] @ git+https://github.com/stdevMac/orb-audio" и команда orb-mcp, сервер MCP по stdio. Без планировщика Spec рендерит render_spec. Страница проекта, она же домашняя страница в снимке API, — stdevmac.github.io/orb-audio.
