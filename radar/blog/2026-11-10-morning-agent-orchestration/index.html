numbrone: штаб, который раздаёт задачи кодинг-агентам

stevenmichaelthomas/numbrone в описании — chief of staff для кодинг-агентов: запросы уходят менеджерам проектов, а те запускают параллельных воркеров в git worktree на herdr. По README это независимый проект сообщества поверх herdr, не продукт команды herdr. С агентом говорит chief: код он не пишет, он маршрутизирует запросы и сообщает, что происходит. На каждый проект — менеджер в своём workspace herdr. Мелочи менеджер закрывает сам, для правок кода поднимает воркера. Воркер — одна задача, своя вкладка и свой git worktree, чтобы задачи не задевали друг друга и вашу рабочую копию. Менеджер смотрит результат до отметки «готово». Отчёты идут снизу вверх: воркер, менеджер, chief, вы. Состояние — текстовые файлы, их можно читать и править. По README это один скилл, один bash-скрипт и три Markdown-файла ролей. Необязательные наблюдатели в README — Linear, GitHub issues, Sentry, Datadog и сбои CI: chief смотрит источники на несколько проектов, менеджер — источники своего. Лицензия MIT, язык Shell, 110 звёзд, push 9 ноября 2026. На момент запроса репозиторий не был архивным.

Смотреть тем, кто ведёт несколько репозиториев и хочет одну точку, куда отдать задачу обычным языком, а параллельную работу по коду видеть в herdr. Нужны herdr, git и jq, macOS или Linux. Агент по умолчанию — Claude Code; README называет ещё Codex, Gemini и OpenCode. Мерж, push и деплой происходят только по вашей команде. numbrone close не снимает worktree с незакоммиченными изменениями и ветку оставляет. Агенты работают на вашей машине с вашим доступом. Воркеры по умолчанию останавливаются на каждом запросе разрешения и в herdr видны как blocked, пока вы не ответите. Этот выпуск скрипт не запускал.

Aspen: свой Git-сервер под одновременные push агентов

reason-machines/aspen в описании — Git-сервер, который поднимают у себя, под трафик масштаба агентов: паки в объектном хранилище, история каждой ветки в Postgres. Статус в описании и в README — pre-alpha. По README сервер говорит обычным Git по HTTP и SSH, отдельный клиент не нужен. Паки лежат в объектном хранилище, история веток — в PostgreSQL; на одной машине хватает SQLite и локального каталога. Один бинарник. Зеркальный режим ставит Aspen перед GitHub или GitLab. Дизайн, по README, опирается на опубликованные описания внутреннего Git OpenAI (Pando) и хранилища Cursor (Origin). Это независимая реализация: общего кода нет, аффилиации с OpenAI или Cursor нет. В README указано демо — общий холст, где каждый штрих — git push: place.reasonmachines.com. Лицензия Apache-2.0, язык Rust, 100 звёзд, push 7 ноября 2026. На момент запроса репозиторий не был архивным.

Смотреть тем, кто ждёт много одновременных push и fetch от агентов и CI и хочет свой сервер. Ограничения прямо в README: опубликованных релизов нет, форматы хранения ещё могут измениться, данные, которые жалко потерять, класть рано. Свой launch gate проект не закрыл. Готовых бинарников нет, сервер собирают из исходников. Force-push и удаление ветки требуют -o force, lease или URL конкретной ветки. Partial clone, репозитории SHA-256, веб-интерфейс и код-ревью README не даёт. SSH принимает ключи Ed25519 и ECDSA. Снимок всех веток разом сервер не обещает: читатель нескольких веток может увидеть каждую в свой момент. Цифры скорости в README сняты с одного прогона, и сам текст просит считать их ориентиром. В этом выпуске они не повторяются. Сервер в этом выпуске не собирался.

Agent-VScreen: агент работает в приложениях, экран телефона остаётся вашим

kilolonion/agent-vscreen в описании — фоновый виртуальный экран для любого Android-агента: приложения открываются на невидимом дисплее, пока вы пользуетесь телефоном. CLI, MCP и HTTP, привилегии через Shizuku, root не нужен. По README на своём экране остаётся плавающее окно с тем, что делает ИИ: его можно перехватить или остановить. Агент с терминалом вызывает vscreen, агент с MCP подключается к MCP, свой код ходит по HTTP. Приложение модель не вызывает: что означает экран, решает модель агента. После действия возвращаются текущий экран, видимый текст, нажимаемые элементы и скриншот. OCR на устройстве, офлайн. Версия в README — 1.1.7 (versionCode 9), пакет com.kilon.agentvscreen, Android 11 и новее (с 14-й — рекомендация README), архитектура arm64. В настройках README указывает языки: системный, китайский и английский. Лицензия MIT, язык Kotlin, 45 звёзд, push 9 ноября 2026. На момент запроса репозиторий не был архивным. Модели OCR из PaddleOCR в комплекте идут по Apache-2.0.

Смотреть тем, кто хочет, чтобы агент на Android открывал другие приложения и не занимал основной экран. Нужен запущенный Shizuku. Сервис по умолчанию слушает только 127.0.0.1:18765. Доступ с другого устройства в README выключен, пока его не включат через Tailscale. Публичную ссылку приложение не предлагает. Токен в README приравнен к управлению телефоном: в публичные карточки, общие конфиги и скриншоты его не кладут. Приложение можно запретить целиком или оставить только для чтения. Кнопки оплаты, удаления и похожие ждут подтверждения. Этот выпуск APK не ставил.

ztd-charts: 36 графиков на SVG и спецификация для агента

Junhan2/ztd-charts в описании — 36 анимированных интерактивных React-графиков на чистом SVG, с CLI и MCP-сервером. По README у графиков нет runtime-зависимостей, peer-зависимость одна — React. Тот же график задаётся JSON-спецификацией с публичной JSON Schema. Её проверяют и рисуют CLI, MCP-сервер и агентский скилл: на выходе PNG, SVG или HTML. Группы в README: доли, иерархия, потоки, сравнение, тренд, распределение, связи и KPI. Документация и галерея — на charts.ztd.app/docs. Пакеты: ztd-charts, ztd-charts-cli, ztd-charts-mcp. Пример подключения MCP в README дан для Claude Code. Cursor и Claude Desktop в той же строке отнесены к руководству. Лицензия MIT, язык TypeScript, 170 звёзд, push 10 ноября 2026. На момент запроса репозиторий не был архивным.

Смотреть тем, кто собирает дашборд на React, и тем, кто хочет, чтобы агент отдавал график спецификацией. Числа в примерах README прямо называет выдуманными. Очень большие ряды библиотека сама переводит на canvas. Размер графика вместе с общим ядром README оценивает примерно в 12–26 КБ в Brotli. В этом выпуске сборка не замерялась. Язык по умолчанию — en-US, корейский включается локалью ko-KR.
