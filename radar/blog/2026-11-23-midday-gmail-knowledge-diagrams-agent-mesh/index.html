Exo: локальный клиент Gmail для macOS

m1guelpf/Exo по описанию репозитория — быстрый локальный нативный клиент Gmail для macOS, по мотивам Superhuman. В README клиент ходит в Gmail напрямую, стороннего сервера проекта нет, написан на Rust. Установка — файл .dmg из последнего релиза, затем перенос в Applications. Чтобы войти, нужен свой клиент входа Google: в проекте Google Cloud включают Gmail API, Google Calendar API и People API, скачивают JSON desktop-клиента и кладут его в ~/Library/Application Support/Exo/google-oauth-client.json. Exo запрашивает чтение, отправку и разбор почты, настройки почты (фильтры, подписи, автоответ), календари, контакты и каталог организации; если снять галочку на экране Google, вход не проходит. Предупреждение Google о непроверенном приложении в README названо ожидаемым: приложение создаёт сам пользователь. Сборка из исходников: Rust 1.98 или новее, Xcode 27, Ruby 4.0 с Bundler, команда bundle exec fastlane build. Тесты ходят в mock-сервер Gmail из crates/gmail-mock и на серверы Google не выходят. В разделе про ИИ автор пишет, что Exo собран почти целиком инструментами генерации кода, в основном Claude Opus 5.5, и человек сгенерированный код на корректность и безопасность не ревьюил; сам автор приложение проверял и пользуется им каждый день. Лицензия MIT; шрифты, иконки, фото и перенесённый код перечислены в THIRD_PARTY_NOTICES.md. diderot: поиск по знаниям организации

bluesky-social/diderot по описанию — self-hosted поиск и вопросы по знаниям организации: Slack, сессии кодинг-агентов, документы и тикеты. README уточняет состав: Slack, Discord, сессии Claude Code, Codex, ATIF и Hugging Face STS, Notion, Linear, Zendesk и папки Markdown попадают в один журнал событий Postgres, эмбеддинги лежат в Qdrant, агент ищет по этому корпусу и отвечает с цитатами — в Slack и как MCP-сервер. Поиск в README только векторный: ближайшие чанки, которые вызывающему можно видеть, без реранкера и без индекса по словам. У события есть область видимости: закрытый канал Slack виден его участникам, сессию можно оставить только владельцу. Админка — в браузере по пути /admin. Быстрый старт — Docker Compose: Postgres, Qdrant, локальная модель эмбеддингов и сервер; нужны Docker и ключ OpenAI или Anthropic. Ask отправляет этому провайдеру вопрос и текст корпуса, который читает для ответа. Модель для эмбеддингов, Ask, сводок и подписей выбирается в админке: OpenAI, Anthropic или OpenAI-совместимая точка, в том числе шлюз, локальные vLLM или Ollama. open-diagram: схемы, которые проверяют свою вёрстку

lukendeasy/open-diagram по описанию — блоки на Python для плотных архитектурных схем, которые проверяют собственную вёрстку. В скрипте задают панели, плитки, линии и группы. Библиотека меряет каждую подпись по шрифту, расставляет блоки и проверяет картинку: если две панели сталкиваются или линия идёт через панель, сборка называет проблему. save() пишет SVG и PNG, печатает сводку и при ошибках поднимает LayoutError. PNG нужен Google Chrome, Chromium или Microsoft Edge; SVG пишется и без браузера. Установка: pip install open-diagram, Python 3.9 или новее, fontTools ставится вместе с пакетом. Те же схемы можно описать JSON или flowchart Mermaid. Команды CLI: open-diagram draw, check и describe. describe возвращает, что нарисовано, обычными словами; тот же текст попадает в описание SVG. В README есть MCP-сервер: он стартует на компьютере, принимает только JSON и Mermaid и пишет файлы в одну выходную папку. Лицензия MIT; шрифт Inter в комплекте — у The Inter Project Authors, SIL Open Font License 1.1. agora-mesh: агенты на разных машинах, отдельные ветки

kn0sti/agora-mesh по описанию соединяет кодинг-агентов на ваших машинах: они планируют вместе, делят работу и пушат в разные git-ветки. В README это независимый проект сообщества, не связанный с Anthropic, ранняя версия 0.6.0. Собран под Claude Code; комнаты также собирались с Codex, OpenCode и Hermes Agent. Логин и файлы остаются на своей машине, логин и ключ agora-mesh не видит. Своего сервера, VPN и MCP нет: машины соединяются напрямую со сквозным шифрованием, публичные реле iroh помогают им найти друг друга и несут трафик, если прямого пути нет. Подключённая машина может запускать команды на вашей: README просит соединять только те машины, которым доверили бы шелл. Демо ./agora demo показывает процесс на скриптовых агентах, токены не тратит и убирает за собой. По расходам README пишет, что комната токены не экономит: на одном коротком вопросе планирования у автора комната из двух потратила примерно в 9 раз больше токенов, чем один агент, из трёх — примерно в 13. Это повторные прогоны на одной дешёвой модели, комнаты и одиночный агент без инструментов; сравнение стоимости, не качества планов. Что README отмечает как уже запускавшееся: комнаты и фаза работы между Mac и Linux с Claude Code; комнаты с Codex, OpenCode и Claude Code на DeepSeek и GLM; обсуждение с Hermes. Что не запускали: два разных аккаунта в одной комнате, настоящий NAT между сетями, Windows кроме автоматического демо, рабочая фаза с Hermes. Для Claude Code в README указана установка плагина claude plugin install agora-mesh --marketplace kn0sti/agora-mesh.
