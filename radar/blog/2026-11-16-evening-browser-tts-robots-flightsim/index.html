yab: браузер для macOS

yetanotherbrowser/yab — нативный браузер для macOS 15.4+ с приложением-компаньоном для iPhone и Android (сайт yetanotherbrowser.com): по README одно поле служит адресом и поиском, вкладки ставятся сверху или слева, есть закрепления, папки, пространства и поиск вкладок по ⌘K. Движка два — WebKit по умолчанию и Chromium на Apple silicon, на вкладку или на сайт, с расширениями Chrome, DevTools и Web Store; внутри движка работает блокировщик рекламы, ⇧⌘H скрывает элемент, есть режим чтения, плавающее видео и разделённый вид, а ИИ-агенты провайдеров, за которых пользователь уже платит, работают в своих вкладках и не видят приватные вкладки.

Кому: тем, кто хочет такой браузер на Mac и отдельное приложение на iPhone или Android. Репозиторий создан 15.11.2026 и на момент снимка не был архивным; язык Swift, лицензия Apache-2.0, 572 звезды, push 15.11.2026, 21:11 МСК.

tiny-voca: английский TTS

n4ze3m/tiny-voca — небольшой синтез английской речи, обученный с нуля: 4 537 291 параметр, 18 МБ, два голоса американского английского F2 и M2 на 24 кГц. Код, веса, рецепт и датасет открыты (веса и датасет на Hugging Face, демо — tiny-voca.n4ze3m.com); запуск на PyTorch, ONNX Runtime и ONNX Runtime Web в браузере, длинный текст читается по предложениям, параметры --voice, --speed и --pitch-shift.

Кому: тем, кому нужен маленький открытый английский TTS, в том числе в браузере. По данным README скорость около 70× реального времени на четырёх потоках CPU; репозиторий создан 14.11.2026, язык Python, лицензия Apache-2.0, 569 звёзд, push 16.11.2026, 18:21 МСК.

PEAR: роботы через RL в симуляции

mit-han-lab/pear — PEAR, Post-training Engine for Agentic Robotics: обучает модели рассуждения нативно пользоваться роботами через RL в симуляции. Это инфраструктура статьи «Training Reasoning Models in Simulation to Natively Use Real Robots» (блог, arXiv 2611.18562): по README открытая модель рассуждения на 27B учится пользоваться настоящими роботами целиком в симуляции, без демонстраций. Стек — асинхронный RL на veRL, GRPO, FSDP и sequence parallelism, выгрузка KV через LMCache, ядра для H100, H200 и GB300, симуляторы MuJoCo на том же кластере Ray.

Кому: исследовательским группам с GPU-кластером — это исследовательская инфраструктура, не домашний инструмент; репозиторий создан 13.11.2026, язык Python, лицензия Apache-2.0, 485 звёзд, push 16.11.2026, 10:54 МСК.

fableflight: авиасимулятор на Rust

Rolandjg/fableflight — авиасимулятор открытого мира на чистом Rust. README сообщает, что проект создан с помощью ИИ («vibe coded»), и упоминает погоду реального мира и живой воздушный трафик; сборка — cargo build --release, интерфейс на английском или французском, джойстик, рычаг газа и педали руля можно назначить, есть инверсия, мёртвая зона и пресеты.

Кому: тем, кто собирает открытый авиасимулятор на Rust. Это хобби-проект, зрелость стоит проверить самостоятельно; репозиторий создан 13.11.2026, язык Rust, лицензия MIT, 286 звёзд, push 16.11.2026, 20:26 МСК.
