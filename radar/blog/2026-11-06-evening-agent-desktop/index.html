agent-desktop: computer use через дерево доступности

Описание vercel-labs/agent-desktop: CLI для computer use у ИИ-агентов — чтение и управление десктоп-приложениями на macOS, Windows и Linux через дерево доступности ОС, без скриншотов и сопоставления пикселей. Снимок отдаёт JSON со ссылками (ref) на элементы; агент кликает или печатает по ref, снова снимает UI и повторяет цикл. Модели внутри пакета нет: цикл живёт в вашем агенте. Ставится через npm как agent-desktop, есть нативные бинарники и Homebrew на macOS/Linux. README предупреждает, что снимки, буфер обмена и артефакты отладки могут содержать приватный контент с рабочего стола. Лицензия Apache-2.0, по API основной язык Rust, 17951 звезда, push 6 ноября 2026.

Это слой доступности, а не готовый агент. Насколько стабильны permissions на вашей ОС и конкретном приложении, в карточке не измерялось: смотрите agent-desktop status и раздел Installation в документации проекта.

worktrunk: git worktree под параллельных агентов

max-sixty/worktrunk описан как CLI для управления git worktree, рассчитанный на параллельные сценарии с ИИ-агентами. Топики репозитория включают agents, claude-code, codex, developer-tools, git и worktrees. Документация и сайт проекта — worktrunk.dev. Лицензия в файле LICENSE: MIT OR Apache-2.0 на выбор; основной язык Rust, 11763 звезды, push 6 ноября 2026.

Полезно, если несколько агентов должны править один репозиторий в разных ветках без пересечения рабочих деревьев. Конкретные команды старта и слияния берите из README и docs на момент установки: в карточке они не пересказываются дословно.

auto-ontology: онтология и provenance для агентов

Описание NVIDIA/auto-ontology: Python-фреймворк для семантического, графового слоя рассуждений над данными. Авторы пишут, что агентам нужен контекст: где лежат данные, что они значат, можно ли их использовать, как строить запросы, откуда provenance и что похоже. Библиотека строит слой из корпоративных метаданных, согласует определения между системами и отдаёт его harness через MCP, CLI и API. В README заявлены text-to-SQL с опорой на NVIDIA NIM, каталог в Postgres, RBAC через Better Auth, веб-UI и деплой через Helm или Docker Compose. Внешние вклады в проект на момент текста не принимаются. Лицензия Apache-2.0, Python, 8696 звёзд, push 6 ноября 2026.

Это слой смысла над данными, а не замена вашей СУБД. Качество ответов зависит от метаданных и сертификаций в вашей среде; бенчмарки text-to-SQL авторы выносят в отдельный репозиторий ontology-sql-eval.

Scenario skills: медиа и DCC для coding-агентов

scenario-labs/skills описан как набор Agent Skills для coding-агентов (Claude Code, Cursor, Codex, Copilot и других): production-ready картинки, видео, аудио, текстуры, skybox и 3D через Scenario MCP, с выбором модели и оценкой цены до траты, плюс отдельные «экспертные» семьи навыков, которые гоняют локальные DCC и движки (Blender, Maya, ZBrush, Unreal, Unity, Godot, Roblox Studio) и требуют установленного приложения, а не только MCP. Формат skills — agentskills.io. Лицензия MIT, Python, 3380 звёзд, push 6 ноября 2026.

Скиллы Scenario идут через MCP Scenario; экспертные папки — через ПО на машине. Объём проверки каждой семьи указан в README соответствующей папки: в карточке это не дублируется.
