xnulinux: XNU внутри Linux

AFK-surf/xnulinux собирает XNU, открытое ядро macOS, и загружает его модулем xnu.ko в немодифицированное ядро arm64 Linux: процессы macOS идут на тех же процессорах рядом с процессами Linux, без гипервизора. README пишет, что на обычном ядре Ubuntu insmod xnu.ko доводит системный диск macOS 27, сделанный установщиком Apple, до рабочего стола. Смотреть тем, у кого есть arm64 Linux с PAC, страницами 4 КБ и не меньше 16 ГБ памяти: README называет виртуальную машину на Apple Silicon и bare-metal NVIDIA DGX Spark. Лицензию GitHub в снимке не определил (NOASSERTION); в README лицензии разложены по каталогам, бинарников Apple в репозитории нет, проект к Apple не относится.

shrink-anything: меньше кода, те же тесты

EL4CTEO/shrink-anything находит мёртвый код, неиспользуемые файлы, зависимости и ассеты, удаляет их и оставляет вырезание, только если ваша команда проверки завершается с кодом 0 и тестов запускается не меньше, чем до него. Смотреть тем, кто хочет уменьшить кодовую базу и отдать решение своим тестам, в том числе после правок агента. Проверка, которая уже падает, по README отклоняется: ей нечего доказывать; сами тесты инструмент не меняет, а публичный метод, экспорт библиотеки и файл, который подхватывается по соглашению, без агента или флага --aggressive не режутся. Язык в снимке — Rust, в README есть установка через npm и cargo, лицензия MIT.

dashsplat: регистратор в трёхмерную сцену

R44VC0RP/dashsplat по описанию репозитория превращает запись автомобильного регистратора в трёхмерный мир, по которому можно проехать снова: Gaussian splats, атлас дороги, отслеженные машины и вид сзади, который дорисовывает диффузионная модель. README сужает источник до шести камер одной поездки Tesla Model 3 (HW4): проект любительский, медленный, грубый, настроен на эту машину и к Tesla не относится. Смотреть тем, кто разбирает такой пайплайн на Mac с Apple Silicon или на x86-64 Linux с NVIDIA. Код по README — Apache-2.0, часть скачиваемых моделей README относит к некоммерческим; калиброванного стенда и примера сцены в репозитории нет, сгенерированный вид есть только с камеры преследования, а сантиметровый атлас дороги из описания GitHub отчёт стадии дороги в README своими целями замера не подтверждает — этот выпуск замер не повторял.

pathviz: путь пакета по netfilter

iximiuz/pathviz рисует в браузере путь пакета по хукам netfilter и стадиям raw, mangle, nat и filter: какие стадии пакет прошёл, где остановился и что у него переписал NAT. README ограничивает задачу учёбой и демонстрацией на нескольких пакетах в секунду, не большим потоком. Смотреть тем, кто готов поставить это на Linux с правами root: нужны nft, ss и модуль ядра nfnetlink_log; для пробы README даёт онлайн-площадку и локальное демо. Зонды ставятся таблицей nftables inet pathviz и снимаются при остановке; токен веб-интерфейса README просит хранить как пароль, по умолчанию интерфейс слушает 127.0.0.1:7070, лицензия MIT, язык в снимке — Go.
