turbo-browser-mcp: меньше ходов у браузерного агента

Tthanh2k6/turbo-browser-mcp в описании GitHub — MCP-сервер на Playwright, который сокращает ходы и токены агента: заполнение формы одним вызовом, снимки только изменившегося, пакеты шагов и запрет отправки, включённый по умолчанию. README называет 11 инструментов. smart_fill_form заполняет форму целиком, включая поля React, select, combobox, редакторы и файл с диска. inspect_compact умеет вернуть только элементы, которые изменились с прошлого снимка. batch_actions проводит список кликов, клавиш, шагов формы и чтений страницы одним вызовом. Кнопки, похожие на окончательное действие (Submit, Send, Publish, Pay, Confirm и их корейские, японские, китайские и вьетнамские соответствия), по умолчанию блокируются: агент может заполнить форму и оставить последний клик человеку. Снять запрет можно флагом allowSubmit: true на вызов или ключом --allow-submit при старте. README прямо пишет, что сервер не прячет автоматизацию: без stealth-патчей, смены отпечатка и решения CAPTCHA. Если сайт проверяет человека, инструмент wait_for_human отдаёт вкладку человеку и продолжает ту же сессию. По умолчанию сервер сначала пробует Chrome, уже слушающий http://127.0.0.1:9222, иначе поднимает свой headless Chromium. Нужны Node 20+ и браузер на базе Chromium. Запись скриншотов, PDF и storage README ограничивает каталогом TURBO_BROWSER_SAVE_ROOT или текущим рабочим каталогом. Для Claude Code README даёт claude mcp add turbo-browser -- npx -y turbo-browser-mcp. Замеры в README сняты на локальных фикстурах и считают размер ответа инструмента, не время модели; сравнение с другими браузерными стеками README помечает как один прогон на ячейку. Этот выпуск замеры не повторял. Страница пакета в поле homepage API — npmjs.com/package/turbo-browser-mcp.

Кому: тем, кто уже гоняет браузерного агента в Claude Code или Cursor и хочет меньше повторных снимков страницы, с последним кликом на человеке.
