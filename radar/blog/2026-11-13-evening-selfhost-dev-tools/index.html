elu: ревью в worktree, push после /publish

ELU-Labs/elu — полноэкранное терминальное приложение. Сессии кодинга идут поверх уже установленных CLI Claude Code и Codex, рядом работают боты-ревьюеры. Установка в README: npx -y @elu-labs/elu. Для запуска README просит macOS или Linux, Node 22 или новее, Git, вошедший Claude Code и установленный Codex. Проверки проекта выполняет песочница Codex.

Каждая правка ложится в отдельный git worktree на своей ветке. Затем проходят проверки проекта и ревью @reviewer. В удалённый репозиторий ничего не уходит, пока не набрать /publish и не подтвердить отправку. Файл, похожий на секрет, README показывает на примере .env: такой файл останавливает сессию. pibrowse: профили браузера, превью только на macOS

aronhy/pibrowse в README — open-source «fingerprint browser» для раздельных браузерных профилей. Сайт проекта — pibrowse.dev. Держать его можно локально или поднять self-host для команды. Открытое издание README называет бесплатным. PiBrowse Cloud — отдельный платный хостинг, и README пишет, что он в разработке.

Сейчас это превью 0.5.5 и только для macOS на Apple Silicon. Ядро Chromium 157 скачивается отдельно. Нотаризации Apple нет: README указывает открыть сборку вручную через «Открыть всё равно». Сборок для Windows и для Intel Mac в этом релизе нет. Сценарий из README — разные аккаунты в изолированных профилях. Лицензия по снимку API — AGPL-3.0.

rivet-dev/open-orange запускает уже написанные Cloudflare Workers и Durable Objects на AWS, Google Cloud, Azure или своих серверах. README пишет, что код для этого менять не нужно. Сайт проекта — openorange.dev. Команда wrangler dev заменяется на orange dev. Хранилище README помещает на S3.

Нужен проект с конфигом wrangler.jsonc, wrangler.json или wrangler.toml, Node.js 22 или новее и pnpm. Для деплоя README просит Docker. В README есть готовый промпт для кодинг-агента — Claude Code, Codex или Cursor — через Rivet MCP. Лицензия по снимку API — Apache-2.0.

Сервис принимает формат событий Plausible. Посетитель считается как хэш от суточной соли, сайта, IP и user agent. Сам IP README не хранит.
