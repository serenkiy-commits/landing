Colab Playground: приложение над Colab CLI

scarletkc/colab-playground в описании GitHub — настольное приложение для Google Colab CLI: аккаунты, GPU-сессии с ограничителями расхода, проброс портов и плагины. README уточняет, что это фронтенд на Rust и GPUI к команде colab, а не редактор ноутбуков и не замена CLI: всё идёт через colab, выкладка модели в ядро не входит и живёт плагином (в комплекте — «Deploy a GGUF model» на llama.cpp). Приложение хранит несколько аккаунтов Google, запускает сессию на CPU, GPU или TPU и пробрасывает порт сессии на 127.0.0.1; автостоп и остановка по простою работают на самой сессии, потолок трат и пол баланса проверяются, пока приложение запущено, а скрипт плагина README выполняет на сессии Colab, не на компьютере.
