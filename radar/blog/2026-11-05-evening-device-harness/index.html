agent-device: слой устройств для агента, который пишет код

Описание callstack/agent-device: открытый слой устройств для ИИ-агентов, которые пишут код. Через CLI, встроенный MCP-сервер или типизированный Node.js API агент управляет приложениями на мобильных, вебе, ТВ и десктопе — на устройствах и симуляторах, локально или в облаке. В README перечислены iOS, Android, HarmonyOS, tvOS, Android TV, Fire TV, Amazon Vega OS TV, web, macOS и Linux. Агент читает снимки accessibility вместо одних скриншотов, действует по refs и селекторам и сохраняет доказательства для проверки. Лицензия MIT, TypeScript, 5277 звёзд, push 5 ноября 2026.

Сайт проекта: agent-device.dev. Насколько слой закрывает ваш стек устройств, видно только после установки и прогона на своём приложении.

argent: ассистент жмёт кнопки на симуляторе и профилирует экран

software-mansion/argent даёт ассистенту прямое управление симуляторами iOS, эмуляторами и устройствами Android, ТВ (Apple TV, Android TV, Fire TV) и приложениями Electron/Chromium. В README заявлены тапы, свайпы, жесты, ввод, аппаратные кнопки, D-pad на ТВ, мышь и клавиатура на десктопе; запись пути как e2e и повтор; визуальная регрессия; профилирование через Hermes, React DevTools, Xcode Instruments и Perfetto; логи и сеть. Запуск из README: npx @swmansion/argent@latest init. Лицензия Apache-2.0, TypeScript, 3163 звезды, push 5 ноября 2026.

Сайт: argent.swmansion.com. Совместимость с вашим React Native или нативным проектом нужно проверять отдельно по документации.

collie: Claude Code и Codex с телефона через PWA

AltanS/collie — открытый мобильный клиент для Herdr (с экспериментальной поддержкой herdr-core, tmux и zellij). Это self-hosted PWA: с iPhone или Android открываете URL и отвечаете агенту с мобильной клавиатуры. В README названы Claude Code, Codex и OpenCode. По умолчанию сервис отдают через Tailscale; голос и push описаны в docs репозитория. Лицензия MIT, TypeScript, 1584 звезды, push 5 ноября 2026.

Демо и сайт: colliepwa.dev. Нужен свой инстанс и доступ к терминальному мультиплексеру — без этого клиент не к чему подключить.

openharness: один командный центр для агентов на разных машинах

Описание autonomous-ai/openharness: харнес для coding-агентов и не только. В README рядом названы Claude Code, Codex, Cursor, OpenCode, Devin, Amp, Copilot и ещё семь клиентов; машины (ноутбук, домашний сервер, GPU-бокс) связывают паролем без SSH-ключей, Tailscale и проброса портов. Дальше заявлена работа за пределами кода: CAD, схемы, роботы, игры и музыка. Есть desktop-приложение со ссылкой на загрузку в README. Лицензия MIT, TypeScript, 1427 звёзд, push 5 ноября 2026.

Сайт: autonomous.ai/harness. Список поддерживаемых агентов и сценарий «beyond code» стоит сверять с актуальным README перед установкой.
