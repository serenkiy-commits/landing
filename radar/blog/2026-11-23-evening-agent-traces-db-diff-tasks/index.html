README уточняет состав записи: каждый промпт, вызов модели, вызов инструмента, правка файла и стоимость. Рантайм-зависимостей README не называет; нужен Node.js 22.16 или новее. Лицензия MIT, аккаунт проекта не нужен. Первый запуск в README — npx coding.sh: программа находит агентов, один раз спрашивает и импортирует прошлые сессии. На Windows README просит npx -p coding.sh codingsh. Повторный запуск открывает просмотрщик. Статус в README: до версии 1.0, последняя названная там — 0.1.7. Таблица агентов делит поддержку на статусы. «Verified on real sessions»: Claude Code, Codex CLI и Antigravity CLI (в README — бывший Gemini CLI). «Verified on a real install»: OpenCode, GitHub Copilot CLI, Factory Droid, Goose, Pi, T3 Code и Aider. «Not run live» — адаптер сверяли с документированным форматом, живую установку не гоняли, потому что нужен вход в аккаунт: Cursor CLI, Amp и Devin CLI. db-branch: ветки базы на своих серверах

db-branch/db-branch по описанию в API — мгновенные ветки MySQL на клонах ZFS, кластер на виртуальных машинах и маршрутизация ProxySQL. README шире того же поля: ветки и для MySQL, и для PostgreSQL, copy-on-write, на своих серверах. Статус в README — Beta: пользоваться можно, API и подробности командной строки могут измениться до 1.0. Проект назван независимым и написанным с нуля. База — датасет ZFS с уже загруженными данными; ветка — клон снимка, свой сервер СУБД на своём порту, при создании ничего не копируется. Одни и те же операции README отдаёт через CLI, REST, веб-консоль и MCP-сервер: агент может создать ветку, прогнать запрос или миграцию и удалить ветку. Несколько узлов собираются в кластер Raft; ProxySQL по выбору направляет клиента на ветку по имени пользователя или по комментарию /*db_branch='name'*/ в запросе. Требования в README: Ubuntu 24.04 LTS или 26.04 LTS и пул ZFS. Установка оттуда — apt-репозиторий apt.db-branch.com, затем sudo db-branch init --pool <zpool>. Демо в браузере README описывает как консоль внутри страницы: настоящая база не создаётся. Про длительность README пишет про свой тестовый кластер из трёх узлов: ветка PostgreSQL готова примерно за 0,5 с, ветка MySQL примерно за 3 с, при создании копируется 0 байт. Этот выпуск замер не повторял. Ограничения из того же README: ветки одноразовые, расходящиеся записи разных веток нельзя слить обратно в базу как в Git; внутри одной ветки branch merge может логически слить изменения между линиями истории, которые оставил branch restore. Агент с доступом к ветке читает всё, что в неё загрузили: маскировать README просит на снимке базы, а не после ветвления. Редакции: ядро этого репозитория — Apache-2.0 (ветки, базы, рантаймы, кластер, CLI, API, консоль, MCP, мониторинг, уведомления, анонимные ветки с лимитами, обновление базы по расписанию, резервная копия состояния кластера). Модуль proxysql — бесплатный пакет в том же apt. Платные модули (auth/SSO, audit, history, diff, хранилище FSx) — отдельные закрытые пакеты с ключом лицензии. Облачной версии README не описывает. dffy: diff в терминале

amalucelli/dffy по описанию — быстрый просмотр diff и ревью для git в терминале, вместе с тем кодинг-агентом, который уже стоит. README: в репозитории git команда открывает полный экран, дерево файлов слева и diff справа, split или unified; если вывод в трубу, печатает diff. Первые файлы показывает, пока остальные считаются в фоне. Ревизии — те, что понимает git. dffy checkpoint сохраняет рабочее дерево, dffy --since-checkpoint показывает только то, что изменилось с тех пор; пример в README — ход агента. dffy --json отдаёт JSON Lines. dffy mcp — MCP-сервер: агент без шелла читает файлы изменения постранично и комментарии ревью, может ответить в треде или применить подсказку. dffy agents setup ставит skill для Claude Code, Codex, Pi и Amp; skill велит отвечать в тредах своим именем и не закрывать и не публиковать их. Плагины README помечает как экспериментальные и отдельными программами: рендер Markdown и Mermaid, ревью pull request на GitHub (dffy pr 123, нужен вошедший gh) и dffy-agent — клавиша a на треде просит Claude Code, Codex или Pi ответить только чтением. Установка в README: brew install --cask amalucelli/tap/dffy или скрипт install.sh с raw.githubusercontent.com; сборка из исходников вынесена в docs/install.md. Про крупные репозитории README пишет «вплоть до размера ядра Linux» и приводит свою замерку: открытие диапазона Linux v6.0..v6.1 (13 168 изменённых файлов, патч 48 МБ) до первой изменённой строки — 8,1 мс; как pager тот же патч, по тем же строкам, идёт потоком при 3,1 МБ собственной памяти. Этот выпуск замер не повторял. Лицензия в README и в поле лицензии API — MIT.
